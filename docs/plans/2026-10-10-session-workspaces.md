# 会话隔离与共享工作区

目标：默认按 Codex 会话隔离，同一会话重开恢复；显式指定名称的共享工作区让其他会话接续已保存作品。保持项目隔离、本机运行和旧存档兼容。

设计：每个工作区独立服务、保存目录及 latest.txt。`--session` 优先于环境中的 CODEX_THREAD_ID / CODEX_SESSION_ID；没有身份时创建新 UUID。`--shared NAME` 进入同项目的命名共享工作区，`--shared default` 访问原有项目存档。目录标识使用 SHA-256，拒绝保存路径中的符号链接，防止别名共用或逃出项目。启动复用核对项目、目录、工作区身份及版本。

共享是保存后接续，不是实时协同。共享页面 URL 带当前会话 client 身份，浏览器草稿和历史按成员分别保存；成员当前画布是已保存到共享工作区的清洁状态且共享 latest 已更新时，重开加载共享最新作品。首次进入空工作区、尚未修改的练习画布也可接续首次共享保存。未保存草稿、本地导入或仅另存为的作品继续恢复，提示共享已有新保存；浏览器记录单独保留 workspaceClean 标识区分本地清洁和可接续共享的清洁状态。每次手动保存创建独立版本。
