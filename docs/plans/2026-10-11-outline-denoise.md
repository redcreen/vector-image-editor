# 外轮廓去毛边与贴合修正

用户反馈：提高平滑后，毛边仍成为尖角，曲线在部分长弧处偏离实物。现有外轮廓直接简化像素边界，再估算控制柄；减少节点并不能解决这两个问题。

实现范围：仅改进提取外轮廓，不改变线条提取或用户已有作品。

1. 在外轮廓中增加独立的去毛边尺度（原图像素，0 可关闭，界面默认 8）。先处理细小突出和缺口，再拟合曲线。
2. 外轮廓使用有误差约束的贝塞尔拟合。原“平滑程度”改为“拟合误差”（默认 2 px），较小值更贴合，较大值减少节点；保留重要凹口，避免长弧失控外鼓。
3. 预览响应两个参数，数值按原图像素映射到计算分辨率。点击仍生成新曲线，保留图片及已有曲线；支持撤销重做。
4. 先增加算法与浏览器失败回归，再实现。用真实布料图片核对默认效果、节点数量及主要凹口；运行要求的基础与服务检查，以及两种提取的浏览器回归。
5. 验证后安装共用 Skill，核对发布文件；保留用户画布，不擅自刷新或覆盖。说明新版仅影响重新提取。

验收：同色细毛边不再生成尖刺，连续大弧贴合主体；明显凹口保留；去毛边关闭仍能保留细节；拟合偏差受所设误差控制；两项参数确实影响预览与最终结果。
