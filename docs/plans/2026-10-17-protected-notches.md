# 明确定义并保护剪口

用户已批准：框选连续节点后设为剪口；拟合保持形状，整体拖动后展开准确带回。使用 1 号裁片副本测试，保留原页面。

## 实现与验收

- [x] 节点的可选 notchId 标记连续剪口，定义/取消不改变坐标，支持撤销、保存、本机恢复。
- [x] 同索引的临时缝边跨过剪口开口，绕行长度不参与对合；真实纸样轮廓不改变。
- [x] 剪口采用根部位置和局部方向作刚性随动。仅整体拖动其节点，未修改节点/控制柄完全不变。
- [x] 局部拟合只显示完整落在所选范围的剪口；范围切入剪口时自动包含整个剪口，避免剪断保护。
- [x] 单独测试几何，以及浏览器框选、定义、拟合、拖动、展开、撤销、恢复。
- [x] 从指定 1 号原版读取副本演示并量化误差；运行项目检查，发布共用 Skill、核对资源、同端口更新服务。

几何在 notches.js；入口和格式验证在 app.js/server.py；随动在 fitting.js。子代理独立实现几何及其单元测试，主代理负责交互、集成和发布。避免修改已有无关工作。
