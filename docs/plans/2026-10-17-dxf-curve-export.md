# DXF 曲线导出选项

用户要求导出时可选择保留曲线或原有折线方式。保持折线为默认，保留毫米标定、可见范围、图层与闭合状态。

- [x] DXF 增加 `spline` 模式：每条曲线输出一个三次分段 Bézier SPLINE，内部节点重复三次、端部四重结点；保留尖角、控制柄、关闭边和所有直线段。纯直线路径仍用 LWPOLYLINE。
