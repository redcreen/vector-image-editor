# 图层合并与成组

目标：图层支持多选、成组/解组及合并，曲线、图片、文字保持可编辑，操作可撤销并可保存恢复。

方案：沿用 v1 格式与图层数组。组使用可选 `kind: group` 与子层 `parentId`；组本身没有元素。兄弟图层沿用数组顺序，绘制递归展开组。合并使用可选 `items` 保存混合元素的绘制顺序。图层多选进入编辑状态快照。

验收：

- Shift 或 Cmd/Ctrl 点击多选；右键和面板按钮提供成组、解组、合并。
- 组支持折叠、嵌套、重命名、排序、整体选取移动、隐藏、锁定和删除；子层仍独立可编辑。
- 成组和解组不改坐标；合并不连接曲线、不栅格化，保留叠放顺序。成组和合并要求同父组内相邻图层，避免改变相对未选图层的叠放顺序；可见性或锁定状态不同的图层提示先统一，避免合并后无法单独恢复状态。
- 撤销/重做恢复结构与多选；旧 JSON 兼容，新 JSON、历史副本与 SVG 保持结构对应的显示效果。
- 节点单测、临时项目浏览器交互和保存服务验证通过后安装共用 Skill 并核对副本一致。

实施：先补图层模型失败测试，再实现模型和面板交互；保存服务验证与 SVG 递归导出由独立子任务负责；最后验证并更新说明、发布。
