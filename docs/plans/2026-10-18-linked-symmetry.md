# 曲线关联对称

已获用户授权直接实现，使用现有工作区，保留既有修改和所有作品。

目标：镜像时自动记住来源两侧与轴；显示开关不解除关联；整体变换后轴跟随；连接成闭合轮廓后可指定一侧预览并同步；撤销、自动恢复和 JSON 保留关系。

实现：新增 symmetry.js 几何模块，使用每段两端的 incident tags 保留两侧身份和方向，doc.symmetryLinks 保存轴。geometry.js 在分段、反向、连接时传递标记。layers.js 在完整关联对象变换时更新轴。app.js 提供默认关联选项、显示开关、同步预览、选中两侧、解除关联和序列化。独立副本清除关联标记，旧作品不自动猜测。
