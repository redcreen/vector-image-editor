# 编辑器状态栏工具

目标：原生 macOS 状态栏图片编辑图标，管理各项目/session 的本机编辑器。

- [x] 本机管理：启动登记、发现旧服务、聊天标题默认名称、新建独立空白页面、名称持久化；完整保留共享 URL 的 client。
- [x] 网页：顶部及标签显示「通用矢量图编辑器 · 名称」，可改名；菜单改名自动同步，不刷新画布。
- [x] 删除：默认关闭服务并移除，保留文件；网页报告未保存状态，有未保存修改拒绝关闭。旧服务只移除列表；共享服务仍有其他列表成员时只移除本成员。
- [x] 原生界面：列表打开/改名/垃圾桶、新建及项目选择、退出；退出仅退出状态栏。
- [x] 验证：85 项基础、15 项保存服务、8 项工作区、7 项管理专项、57 项浏览器回归通过；Swift 编译、完整应用签名和系统启动验证。界面自动化连接超时，原生点击未实测。
- [x] 同步共用 Skill，安装并启动本机应用；无开机启动项。共用版名称及删除保护浏览器测试通过，14 个工具/菜单文件与源码一致。

实现边界：`editor_registry.py` 管理本机登记和名称，`manager.py` 提供原生 UI 的 JSON 命令，现有 `server.py` 增加名称和安全关闭接口；`editor-session.js` 负责名称及未保存状态同步。原生 Swift 界面与后端独立实现。保存格式与工作区路径不变。
