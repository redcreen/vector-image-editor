# 画布图层定位与 Ctrl 临时平移

- 点击已选或未选的曲线、节点、控制柄、图片、文字时定位所属图层，清理陈旧的图层多选，不清除元素多选和节点/线段状态。仅改变选取目标；画线、文字创建、提取、测量等工具的创建动作保留当前目标图层。
- Ctrl 作为不进入作品或历史的临时平移覆盖，不调用会清理编辑状态的工具切换。所有画布工具支持；输入框、弹窗和操作重放保持自身按键行为，Ctrl 组合快捷键继续可用。
- 正在拖节点、控制柄、选区、缩放、旋转或新点时，按 Ctrl 暂停原拖动并以当前鼠标位置开始平移；松开恢复原拖动。平移的相机变化与鼠标移动抵消，不改变拖动的图像坐标。
- 鼠标释放、取消捕获和窗口失焦正确结束手势，避免粘住平移；平移不触发双击加点或 macOS Ctrl 点击右键菜单。
- 临时项目浏览器测试先复现失败，再实现；验证节点与交互回归、项目必跑检查后发布 Skill，核对安装副本。
