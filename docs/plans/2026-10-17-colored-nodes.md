# 节点颜色

用户要求给曲线节点设置颜色，便于拟合时识别位置。

- 单选或框选/Shift 多选节点，右侧“节点颜色”常用色块一击应用；自定义色块与清除颜色可用，右键提供入口。
- 节点可选 color 字段保存十六进制颜色；颜色修改不改变曲线坐标、控制柄或线色，支持撤销、JSON 和本机记录恢复。
- 已着色节点在正常画布、拟合原曲线和弯曲结果持续可见；局部仅显示选区内的随动点，剪口点使用剪口的刚性投影。颜色标记不接收指针，不妨碍拖动。
- 验证：批量颜色、几何未变、取消选中仍显示、清除、撤销、恢复，以及两种拟合范围、剪口移动后展开。再运行项目检查、发布和同地址更新，保留原画布。
