# 图片线条提取

目标：导入图片后，切换「提取线条 · T」，悬停实线或虚线预览，点击生成普通贝塞尔曲线。图片与已有作品保持原样，生成可撤销、保存、重新打开及导出。

采用本机浏览器像素处理：指针附近取色 → 相近色细线中心线 → 按端点距离和切线方向连接短段（默认18px，避免跨到同色标注） → 简化与贝塞尔拟合。提供颜色容差、连接距离、平滑程度。后台 Worker 计算，过期预览结果丢弃；隐藏图层不识别，锁定底图可作为参考，输出到可编辑图层。
