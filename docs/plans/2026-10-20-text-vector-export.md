# AI / DXF 文字导出

用户要求：AI、DXF 导出也带文字，测试后直接更新共用 Skill 和原地址服务。

实现：
- 仅在所选可见内容的导出副本中，将文字通过本机 CoreText 字形轮廓转为普通贝塞尔路径；中文、英文、数字、多行、旋转、字号和点位标记均纳入。
- 保留层归属、层顺序、颜色、实际尺寸及相对位置；原画布文字、撤销记录和自动保存不改变。
- AI 和 DXF 两种曲线模式共用轮廓。导出的文字为轮廓线，不再是可输入编辑的文字；SVG 仍保留文字。
- 预览明确显示转曲轮廓数，文件节点数包含这些轮廓，毫米边界按实际轮廓计算。未知字形或不支持的彩色字体明确报错。
- 使用 macOS 系统字体，无网络上传、下载字体或额外运行时安装。

验收：中文/英文/数字、多行旋转、纯文字、多选层及隐藏层、两种 DXF、导出再导入尺寸、原对象不变；运行项目要求的检查及浏览器下载测试。发布后核对安装文件和原端口版本，不刷新用户画布。
