# 拟合中编辑原图和其他位置

用户授权：局部拟合保持预览，贝塞尔/节点等工具可编辑原曲线及其他画布内容；预选原曲线后点击拟合或 N 直接选对边。

- 拟合就绪后默认允许原图操作，预览线不拦截点击；剪口/对合点在节点或选取工具中仍可拖动。B 绘制时可在预览线上做标记。
- 原曲线/对边的真实修改刷新参考几何和弧长；增删点重定位范围边界。拟合预览上的逆向编辑继续使用冻结参考，避免双重变形。
- 原图编辑和其他内容编辑都沿用原有撤销记录；撤销原图操作保持实时预览，退出拟合保留真实数据。
- 预选连续点优先，其次单独一条曲线；无选择仍可两次点边。N 与按钮一致，输入/弹窗/输入法组合时不触发。
- 验证原图节点/控制柄、加删点与撤销、B 画标记、其他曲线调整、剪口随动以及原画布保留；通过后发布并同地址更新。
