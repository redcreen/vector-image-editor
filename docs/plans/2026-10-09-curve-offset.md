# 曲线偏移实现计划

用户已确认：选中曲线后从右键菜单进入「偏移曲线…」，闭合轮廓按 mm/cm 外扩或内收，开放曲线按起点到终点方向向左/右偏移；保留原曲线，生成新的可编辑曲线。

## 实现和验收

- [x] 新增独立 `offset.js` 几何模块；使用本地附带的 Clipper 处理闭合轮廓偏移及凹形分裂，将结果拟合为可编辑贝塞尔节点。
- [x] 自动拼合端点重合的开放曲线，交换反向曲线的控制柄；多段闭合轮廓整体偏移，不跨空隙补线。独立轮廓分别处理，交汇分支提示用户调整选择。
- [x] 距离换算使用既有两点标定；未标定、非正距离、退化轮廓或无有效内收结果阻止生成。
- [x] 画布和曲线列表右键均新增入口，保留已有多选和锁定过滤。设置窗口显示距离、单位及适用的方向；开放轮廓预览带方向箭头。
- [x] 预览只存在于临时 SVG 分组，取消、Esc、刷新不写入作品或历史；应用一次生成，自动选择新曲线，图层/属性继承对应来源，一步撤销重做。
- [x] 几何测试覆盖矩形两种方向、圆弧精度、开放曲线方向、拼合闭合、多轮廓、凹形内收和消失、单位和无效输入。浏览器测试覆盖真实右键、预览/取消、多选、新曲线编辑、历史与保存恢复。
- [x] 更新静态资源及服务版本，旧服务另选端口；通过基础、HTTP、浏览器回归后同步共用 Skill，并验证安装副本及偏移行为。

## 工作分工

偏移几何子任务仅修改新 `offset.js`、供应商资源及 `offset.test.cjs`。主任务修改 `app.js`、HTML/CSS、服务、安装脚本、说明及浏览器测试。保留工作区已有改动及用户打开的画布，不刷新用户页面。
