功能面板
图层›

复选框全选图层，眼睛显示或隐藏全部图层。点击箭头展开内容；拖动元素可换层，Shift 多选。双击重命名，拖动排序；右键成组或合并。

对象属性›

选中文字、曲线或图片后更换图层；支持多选。

当前文字

拖圆点吸附到节点后自动跟随；按 Alt 拖动可解除该端关联。拖方块调整尺寸线间距。单独移动整个标注会解除关联。

调整字号立即生效；按 Enter 或移开焦点确认。拖动文字可移动位置。

位置与尺寸 未选择

2 放大到当前的两倍，0.5 缩小到一半；绕共同中心缩放，曲线自动换色。勾选后保留原件；混选的图片、文字也生成副本。

旋转中心：选框中心

拖动十字圆心设置旋转中心，靠近可见曲线节点自动吸附；Alt 自由放置；与节点重合时按 V 拖动中心。输入本次角度，正数顺时针，负数逆时针；圆柄和角度输入均绕此中心旋转。

拖动曲线、图片、文字或选框内部移动，圆柄旋转（超出画布时自动移回可视区域）；Shift 旋转按 15° 吸附。选中整条曲线后拖角等比缩放（选取、节点工具均支持）；已旋转图片保持宽高比例。

当前曲线

选中曲线后点色块即可改色，可多选一起改色。

      使用帮助›

      左侧工具栏：拖动右边缘调宽，宽时自动排成两列；双击边缘恢复默认，Esc 取消拖动。宽度会自动记住，作品和画布位置保持不变。

      矩形（R）与椭圆（E）：先选图层，再按住鼠标拖动；接近正方形或圆形时显示绿色提示，按住 Shift 约束等宽高。松开生成可编辑曲线，按 F10 修改节点；Esc 取消本次绘制。

      贝塞尔：单击画直线节点，按住拖动拉出弧线手柄。点回起点可闭合；Enter 或 Esc 结束。

      节点或选取：双击曲线加节点。拖方点改位置，靠近对称轴或其他曲线 3 个屏幕像素内自动吸附并显示绿色提示，Alt 临时取消；拖节点或平移整条曲线时，重合线段绿色高亮，邻近的直线段完全平行或非常接近时显示黄色提示，出现“松手对齐”后释放鼠标会自动校正为完全平行；Alt 暂停吸附和提示。拖圆柄改弧度；Delete 删除节点，Alt 拖手柄可单独调整一边。选中节点后 J 切换直线 / 平滑；节点工具点选两点之间的线段后 J 只切换本段直线 / 曲线，两端手柄可独立调整，邻段保持原形。

      断开与连接：选中闭合曲线的任意节点，或开放曲线的内部节点，点“断开连接”（也可右键）。断口两端起初重合，直接拖动当前端点即可分开；靠近另一条开放曲线端点或自身另一端时，松开后选择“连接节点”或“仅保持重合”。确认连接才合并端点或闭合曲线；仅重合保留两个独立点，可分别拖开；Esc 或点击别处也保持重合。也可按 V 单选并拖动整条开放曲线，保持形状寻找连接；多处端点接近时，只提示并询问最近的一对。按住 Alt 临时取消吸附连接，支持一步撤销。

      右键：框选或多选多条曲线后，可用“重合的端点改为连接”，按完整曲线连接完全重合的端点，多个轮廓分别处理并自动闭合，不跨空隙补线；分叉点跳过并提示，可一步撤销。框选节点后可“顺滑所选节点”，保持点位并让连线转折更圆润，可一步撤销。同一曲线连续选择至少三个节点后，“整段圆顺…”可固定首尾及指定必经点，在允许偏差内整体整理；绿色预览，应用后一步撤销。曲线上可加点、测量或镜像；选中开放曲线的单个端点后右键“继续画线”，从首端或末端接着绘制；点击加点、拖动拉出手柄，点回另一端闭合，Enter / Esc 结束，支持撤销及刷新恢复。节点上还可删除或调整类型；空白处可续接当前未闭合曲线，或从这里新画一条。

      对称轴：两次点击画轴，接近水平或竖直自动吸附，移开恢复自由方向；Shift 约束角度。先选曲线可看绿色实时镜像预览；轴画好后可直接拖动两端点改变方向，普通拖动可自由微调水平、竖直附近的角度，按住 Shift 约束角度；点选轴线高亮后直接拖动整体平移，方向键微调，Shift 方向键加大步长；右键“删除对称轴”仅删除轴，原曲线和已有副本保留。Shift 拖动约束方向、Alt 暂停自动吸附，Esc 取消本次拖动。生成镜像默认记住对称关系；改好一侧后右键“以这一侧同步另一侧…”预览并应用。合并闭合后也支持；整体旋转或移动请选中对称两侧，关联轴跟随。“显示对称轴”仅控制显示；解除关联保留曲线。取消“生成镜像时记住对称关系”可反复生成独立副本。只镜像一段时，按 F10 点选线段呈蓝色高亮，再右键“镜像所选片段”；也可点镜像面板同名按钮。生成副本，原曲线保留，可一步撤销。

      测量：连续点击测点，Enter / Esc 结束，Backspace 回退。选段测量时点首段、Shift 点末段。曲线测量为弧长。先用“两点标定”设置已知长度，再切换 mm/cm；未标定时显示 px。

      选取：拖动整条曲线。点击画布元素自动选中所属图层，保留已有多选。滚轮缩放；任意工具按住 Ctrl 或空格拖动画板，松开恢复原编辑状态。拖节点、控制柄、移动、缩放或旋转时也可临时平移，再继续原操作。方向键微调节点，Shift 加大步长。

      复制线段或曲线：节点工具点选两点之间的线，蓝色高亮后按 ⌘ / Ctrl + C，再按 ⌘ / Ctrl + V，生成独立的开放曲线。可先点击目标图层再粘贴；相同比例下粘贴保持原位置，选中副本后直接拖走。选中整条曲线或在曲线列表多选时，复制完整曲线。也可用工具栏或右键菜单复制、粘贴；副本保持线型、用途、节点及控制柄，并自动换成不同颜色，可独立编辑，一步撤销。跨页面按实际比例换算，保持真实大小；空白画布可采用来源比例，已有内容却未标定的画布需先两点标定。来源未标定时，请先标定来源并重新复制。隐藏或锁定图层不能粘贴。

      图片：从截图或其他应用复制图片，点击画布后按 ⌘ / Ctrl + V，自动新增并选中图片图层。拖动可移动，拖角可缩放，支持撤销重做。

      “另存为…”保存含操作记录的 JSON 副本，重开可继续撤销、重做和重放；⌘ / Ctrl + Shift + S。保存给 AI 仅保存当前作品，不含操作记录。

      保存给 AI 后，回聊天说“按最新保存的曲线改”。保存不自动发送聊天，也不修改原纸版。

      可直接拖动示例曲线，或导入自己的底图图像坐标 px · 未设置实际比例

      保存含操作记录的 JSON 副本，重新打开后可继续撤销、重做和重放。

      文件将保存到浏览器的下载位置，可在下载列表中查看。

      绿色为简化轮廓与新节点，原线留作对照。保留尖角、剪口和标注位置。滚轮缩放，拖动画布平移。

        整段圆顺

        首尾点固定，中间点默认可微调。勾选必须经过的点，保留它的准确位置。

        数值越大，调整空间越大；限制作用于整段曲线。未标定时以原图像素 px 计算。

        原线保留作对照，绿色为预览；实心金色点固定，空心绿色点可调整。应用后可一步撤销。

        预览中可滚轮缩放、直接拖动画布平移，也可使用顶部缩放按钮。

        闭合轮廓：正数外扩，负数内收。

        开放曲线：正数向左侧偏移，负数向右侧偏移。左右以起点 → 终点为准，蓝色箭头标出曲线方向。

        允许偏差越小，可能需要更多节点；外扩距离保持不变。

        创建文字

        支持英文字母和数字，例如 01、A1；默认放入“位置标注”图层。标注跟随对应节点或曲线落点，拖动节点、调整形状及旋转时文字保持水平正向；创建后可继续点击节点或曲线标注。

        导出矢量文件

        所选图层：。图层组包含其可见子图层；隐藏内容不导出。

        打印选中曲线

        仅打印选中的可见曲线，保留相对位置，输出黑色线稿；不含底图、文字、节点和辅助线。每页留边 10 mm，附 50 mm 校验线。

        在浏览器打印窗口选择相同纸张和方向，缩放设为 100% / 实际大小，关闭“适合纸张”和页眉页脚。打印后可用尺子核对 50 mm 校验线。

        确认 DXF 单位

        没有可识别的尺寸单位。请选择原文件使用的单位，以保留实际尺寸。

        同步另一侧

        绿色为同步后的轮廓，灰色虚线为当前轮廓。应用后可一步撤销。

        图片区域清理

        红色区域将变透明。只清理目标图片，范围以图片边缘为限，无需标定尺寸；曲线、位置和比例保持不变，可一步撤销。Esc 取消。
