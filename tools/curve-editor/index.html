    怎么画、怎么改

    贝塞尔：单击画直线节点，按住拖动拉出弧线手柄。点回起点可闭合；Enter 或 Esc 结束。

    节点或选取：双击曲线加节点。拖方点改位置，拖圆柄改弧度；Delete 删除节点，Alt 拖手柄可单独调整一边。

    右键：曲线上可加点、测量或镜像；节点上可删除或调整类型；空白处可续接当前未闭合曲线，或从这里新画一条。

    对称轴：两次点击画轴，Shift 约束角度；再选曲线生成镜像副本。原曲线保留，可撤销。

    测量：连续点击测点，Enter / Esc 结束，Backspace 回退。选段测量时点首段、Shift 点末段。曲线测量为弧长，单位 px。

    选取：拖动整条曲线。滚轮缩放；按住空格拖动画板。方向键微调节点，Shift 加大步长。
