# 可编辑曲线格式

扩展名 `.json`，格式标识保留 `daban-curve-editor` 以兼容既有文件；它不限制文件所属项目。节点的 `in`、`out` 为绝对坐标，不能当成相对向量。

```json
{
  "format": "daban-curve-editor",
  "version": 1,
  "title": "曲线示例",
  "width": 1000,
  "height": 700,
  "units": "image-px",
  "newNodeMode": "smooth",
  "image": null,
  "opacity": 0.65,
  "paths": [{
    "id": "curve-1",
    "name": "轮廓",
    "role": "outline",
    "color": "#e04544",
    "dashed": true,
    "closed": false,
    "note": "",
    "nodes": [
      {"x": 200, "y": 350, "in": {"x": 120, "y": 350}, "out": {"x": 280, "y": 350}, "mode": "smooth"},
      {"x": 800, "y": 350, "in": {"x": 650, "y": 200}, "out": {"x": 950, "y": 500}, "mode": "symmetric"}
    ]
  }]
}
```

- 相邻点 A、B 的三次贝塞尔段是 `A → A.out → B.in → B`。闭合路径（至少3点）还要绘制末点至首点这一段。
- `cusp` 尖角：两控制柄独立；`smooth` 平滑：两柄与节点共线、反向，长度独立；`symmetric` 对称：反向且等长。生成节点时坐标应符合其类型，不能只改标签。
- 节点可选 `color` 为 `#RRGGBB` 十六进制颜色，用于节点定位标记。与曲线的 `color` 独立，不改变节点、控制柄或导出几何；同色标记在拟合的原曲线和弯曲视图持续显示，剪口内的节点按刚性剪口投影。省略表示普通节点显示。
- 节点可选 `notchId`（1–80 字符字符串）将同一曲线中至少三个连续节点标记为一个完整剪口，支持闭合轮廓跨零点；两端为开口，定位点为开口中点。标记不改动原几何。拟合的临时缝边用开口弦替代凹入轮廓；真实节点、控制柄仍保存与导出，受保护的剪口整体刚性移动。拆分剪口内部线段时新增节点继承同一标记；重复而不连续的同 ID 或残缺组不参与保护，需取消后重选。
- `newNodeMode` 是新节点沿用类型；每个节点的 `mode` 是其自身类型。读取时区分两者。
- `role` 支持 `outline`、`seam`、`cut`、`note`，只是用途标记，不代表已验证生产参数。
- 可选 `dashed` 必须为布尔值；`true` 表示显示为虚线，`false` 或省略表示实线。它只控制呈现，节点、控制柄和长度计算仍使用同一条连续贝塞尔几何；保存预览 SVG 使用 `stroke-dasharray="8 6"`。
- 曲线的可选 `visible` 必须为布尔值，省略或 `true` 表示显示，`false` 表示单独隐藏。曲线及节点仍保存在 JSON 中，列表保留条目；隐藏曲线不参与选择、编辑、测量、导出范围及 SVG 绘制。实际可见性还受所属图层的 `visible` 限制，重新显示图层不会重置曲线自己的开关。旧版文件省略此字段时保持原有显示行为。
- 可选 `originals` 使用与 `paths` 相同结构，保留修改前参考线；省略时，导入器会将导入的 `paths` 作为初始参考。
- 可选 `mirrorAxis: {"a":{"x":500,"y":100},"b":{"x":500,"y":600}}` 为两个不同像素坐标确定的无限对称轴。省略或 `null` 表示未设置。镜像副本是 `paths` 中具有独立 id 的普通曲线，节点及绝对控制柄均经同一反射变换；原曲线保留。对称轴不属于作品线条，不导出 SVG。
- 可选 `calibration: {"a":{"x":100,"y":100},"b":{"x":200,"y":100},"length":10,"unit":"cm"}` 记录两点的已知实际距离。省略或 `null` 表示未标定；单位仅支持 `mm`/`cm`，长度必须为正数，两点不能重合。换算比例 `mm/px = length × (unit 为 cm 时 10，否则 1) ÷ 两点像素直线距离`，曲线实际弧长为像素弧长乘此比例。可选 `measureUnit` 为测量显示单位 `mm`/`cm`，默认 `mm`；显示 cm 时再将 mm 除以 10。标定不改变节点、控制柄、画板坐标或 `units: "image-px"`，适用于整幅图的统一比例。保存配套预览 SVG 仍为像素尺寸；“导出…”生成的 SVG 使用显式 mm 宽高及原坐标 viewBox。参考线不导出。
- AI/DXF 导入统一将节点、控制柄换算成毫米数值，再记录 `calibration: {"a":{"x":0,"y":0},"b":{"x":1,"y":0},"length":1,"unit":"mm"}`；`units` 保持 `image-px` 兼容标识，物理尺寸以标定为准。AI 的点单位乘 25.4/72；DXF 使用 `$INSUNITS` 或用户选择的缺失单位。旧 JSON 不自动推断此比例。
- 测量是临时界面状态，不写入 JSON。多点距离为相邻点欧氏距离之和；曲线长度应沿三次贝塞尔积分或自适应细分求弧长，不能用节点间直线距离代替。连续段以节点索引定义，第 i 段连接节点 i 和 i+1，闭合末段连接末点和首点。
- 可选底图：`image: {"name":"底图.png","dataUrl":"data:image/png;base64,...","width":1000,"height":700}`，支持 PNG/JPEG/WebP，画板尺寸应与底图一致。
- 坐标以左上为原点、X向右、Y向下。画板外节点也会保存，预览时避免无意裁掉它们。

生成 JSON 后通过编辑器“打开修改”导入，检查曲线和节点。生成源稿保存在当前项目，用户后续保存由程序产生新版本，不覆盖源稿。直接检查最新保存时，不要重新生成近似曲线。

## 可选图层、图片与文字扩展（仍为 v1）

`layers` 和 `images` 必须同时提供；可选 `texts` 省略时等同空数组。`layers` 按从后到前排序，1–200 层；`images` 最多 200 张，`texts` 最多 500 条。每条曲线、图片及文字必须且只能归属一个图层，引用必须存在。旧图层省略 `textIds` 时等同空数组。

```json
{
  "layers": [
    {"id":"layer-1","name":"参考图片","visible":true,"locked":false,"pathIds":[],"imageIds":["image-1"],"textIds":[]},
    {"id":"layer-2","name":"轮廓与标注","visible":true,"locked":false,"pathIds":["curve-1"],"imageIds":[],"textIds":["text-1"]}
  ],
  "images": [
    {"id":"image-1","name":"参考.png","dataUrl":"data:image/png;base64,...","x":100,"y":80,"width":600,"height":400,"rotation":15,"opacity":1}
  ],
  "texts": [
    {"id":"text-1","name":"标注","content":"前片\n尺寸待确认","x":240,"y":120,"fontSize":32,"color":"#222222"}
  ]
}
```

图片的 `x/y` 为未旋转显示矩形的左上坐标，`width/height` 为未旋转显示像素尺寸，可与原始图片尺寸不同；可选 `rotation` 为绕矩形中心顺时针旋转的角度数值，省略时为 0，绝对值最多 1e7；`opacity` 为 0–1。缩放曲线直接更新节点与绝对控制柄坐标，不增加曲线坐标变换字段。图片坐标绝对值和正尺寸均最多 1e7；图层、图片和文字 id 必须非空且唯一，最多 200 字符。

文字的 `x/y` 是未旋转文本框左上角像素坐标，也是旋转锚点，绝对值最多 1e7；可选 `rotation` 为绕该锚点顺时针旋转的角度数值，省略为 0，绝对值最多 1e7。整体旋转时锚点绕共同选框中心变换，同时累加文字角度；`fontSize` 是 1–4096 的像素字号，`color` 必须是 `#RRGGBB`。`name` 最多 80 字符；`content` 最多 10000 字符且不能只含空白，可包含换行。SVG 使用通用 `sans-serif` 字体，多行行高为字号的 1.2 倍。后端为防止画板外文字被裁切，按每个字符最多 1.2 倍字号保守估算预览范围；浏览器画布使用实际字体测量，因此两者可能有小幅差异。

点位标注复用 `texts`，附加可选 `positionMarker: {"x": 100, "y": 200, "pathId": "curve-1"}`，保存标注点的绝对坐标，范围与文字坐标相同。带此字段时 `content` 为 1–32 位 ASCII 英文字母或数字（字符串，保留前导零）；圆点半径为 `fontSize * 0.16`，引线终点是绕文字锚点旋转后的 `(x, y + fontSize * 0.6)`。默认进入“位置标注”图层。可选 `pathId` 为 1–200 字符的所属曲线 ID；关联标注随整条曲线移动、缩放和旋转，曲线旋转时文字 `rotation` 保持 0，标注点和文字位置使用同一变换，混合选择不会重复变换。旧标注无 ID 时，仅在标注点距唯一曲线或节点不超过 0.01 坐标单位时推断关联，实际变换时保存 ID；重合多条曲线或已有 ID 失效时不猜测。可选 `attachment` 记录具体落点：节点为 `{"kind":"node","index":0}`，曲线段为 `{"kind":"segment","index":0,"t":0.5}`，索引从 0 起且小于 10000，`t` 在 0–1，带此字段必须有 `pathId`。局部节点/控制柄修改按节点索引或贝塞尔段参数重算落点，文字增加相同位移且 `rotation=0`；旧标注在首次几何变化时从变化前的位置推断，纯打开不改数据。增删节点优先重映射保留的节点/落点，否则投影到同一所属曲线；断开操作显式分配到对应片段，可靠反向重映射索引和参数。来源曲线删除时保留标注原状，不猜其他曲线；JSON、预览及正式 SVG 导出保留点与引线，AI/DXF 导出将文字、圆点和引线转为轮廓线。普通文字不受此限制。

隐藏图层保留在 JSON 中，但不进入保存预览及 SVG 导出；锁定图层仍显示。同层默认按全局数组中图片、曲线、文字的顺序绘制。省略 `texts` 和 `textIds` 的旧文件保持兼容。

图层组使用可选 `kind: "group"`，其 `pathIds/imageIds/textIds` 必须为空，普通图层省略 `kind` 或设为 `"layer"`。子层的可选 `parentId` 指向组 id，省略或 `null` 为根图层；可嵌套，不允许自引用、循环或引用普通图层。兄弟层按 `layers` 数组中从后到前的顺序排列，绘制时递归展开组；组的隐藏和锁定作用于所有后代，子层自己的开关保留。可选布尔 `collapsed` 保存组的折叠状态，折叠只改变列表。组计入 200 个图层上限。

合并图层可使用 `items: [{"type":"path","id":"curve-1"},{"type":"image","id":"image-1"},{"type":"text","id":"text-1"}]` 保存从后到前的混合绘制顺序。`type` 仅支持 `path/image/text`，引用必须与本层三个归属数组完整对应且不重复；组不得直接保存元素。省略 `items` 使用旧绘制顺序。项目内合并保留全部元素 id、坐标、节点、控制柄及内容，不连接曲线或合成为位图；要求同组内相邻图层、所有后代的有效显示及锁定状态一致。可选布尔 `items[].visible/locked` 表示单个元素的额外显示/锁定限制，省略等同可见且未锁定；它们同样受图层与祖先组限制。

没有扩展字段的旧文件会将曲线归入默认图层；旧 `image` 转为原点处、画板尺寸的锁定图片层，继承 `opacity`。新版保存用 `image: null` 和 `images` 表示图片。保存配套 SVG 包含可见图片、曲线和文字；“导出…”支持选择可见内容或图层子树，AI/DXF 接受曲线与文字，文字仅在导出副本中转为轮廓线；SVG 保留文字，图片应排除。标定保持画板像素比例，移动或缩放元素不改动 `calibration`；不能据此推断每张导入图片的真实尺度相同。


## 可选操作记录扩展（仍为 v1）

“另存为”生成的 JSON 保留普通作品顶层字段，并附带可选 `operationHistory`；“保存给 AI”省略此字段，仅输出当前作品。副本使用紧凑 JSON，保存与打开上限均为 256MB；项目保存服务仍限制 32MB，AI 保存不携带历史。AI 读取副本时如只需当前形状，可忽略该扩展。

`operationHistory` 使用 `{format: "curve-editor-session", version: 1, assets: [...], data: {current: {...}, history: {...}}}`。`assets` 是去重后的图片 data URL；历史快照中的 `dataUrl` 使用 `{asset: N}` 引用。`current` 只含当前编辑状态（`selected`、`ni`、`selection`、`imageSelection`、`activeLayer`、`nodeSelection`、`drawing`、`tool`），其作品来自文件顶层，不另存一份当前作品。

`history` 为 `{version: 1, past: [...], future: [...], pastLabels: [...], futureLabels: [...]}`。每个快照包含普通作品 `doc` 和编辑状态，不能再嵌套操作记录。`past` 按时间从旧到新，`future` 按重做栈从远到近存储；各自与标签数量一致，合计最多 100 步，单个标签最多 200 字符。打开前验证所有快照；损坏记录导致打开失败，保留现有画布和记录。旧 JSON 无此字段时仍按普通作品打开，无法补回未保存的历史。

## 关联对称（可选字段，v1 兼容）

- 文档 `symmetryLinks: [{id, axis: {a:{x,y}, b:{x,y}}}]` 保存每组轴，最多 500 组，id 唯一且长 1–80；缺省即普通独立曲线。`mirrorAxisVisible` 布尔值控制轴显示，缺省 true。原 `mirrorAxis` 仍是绘制新镜像的独立轴。
- 节点可携带 `symmetry: {in?:{id,side,dir}, out?:{id,side,dir}}`。side 为 0/1，dir 为 1/-1（缺省 1），标记入/出线段的归属及方向；每段两端必须一致，反向时互换 in/out 并反转 dir。共享节点允许两个 incident 来自不同侧。
- 分段、反向、连接/闭合会传递标记；同步按连续半边替换，保留目标样式。普通复制/缩放副本移除标签，避免复制品加入原关联。断散或不完整标记拒绝同步，不自动猜测。
- 轴随完整关联对象变换；局部节点修改不改变轴。同步预览不入库，应用一步撤销；轴与关联仅作编辑元数据，不生成额外导出线条。


### 两点尺寸标注

`texts[]` 可选 `dimension: {a:{x,y}, b:{x,y}, offset, unit:"mm"|"cm"}`；与 `positionMarker` 互斥。端点为 image-px 坐标，间距为沿 a→b 左法向的有符号 image-px 值。创建时两点不可重合，已有关联节点移动至重合时显示零距离；所有坐标与间距须有限且绝对值不超过 10000000。`content`、`x/y`、`rotation` 是派生显示值，恢复与导出根据当前 `calibration` 重算，不允许手工改数字。无标定可保留已有标注为“未标定”，但不允许实际尺寸导出。标注作为文字元素继承图层/分组的可见、锁定、顺序；默认“尺寸标注”图层。AI/DXF 输出尺寸线及数字轮廓，不保留标注的参数关系。

`dimension` 另支持可选 `bindings: {a?:{pathId,index}, b?:{pathId,index}}`。`pathId` 指向来源曲线，`index` 为 0–9999 节点索引。空对象明确表示自由端点；省略字段的旧标注可在几何编辑中根据唯一重合节点接续关联。增删与反转节点时前端重映射索引，找不到原节点则解除该端关联并保留最后坐标。保存和导出从完整原文档曲线解析有效关联，再筛选导出图层；不要求来源曲线被导出或可见。缺失引用保留缓存端点，不猜测其他节点。

### 提取轮廓来源图片

曲线可带 `sourceImageId`（1–80 字符字符串），记录提取时的原图片 ID，供“反选图片外区域”跨图层定位；不是几何/标定参数。JSON、自动记录及撤销保留它。来源已不可编辑时拒绝清理；只复制曲线时清除此关联，与图片一起复制时重映射为图片副本 ID。临时圈内/圈外选区不写入文档。
