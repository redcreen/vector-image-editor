# 通用矢量图编辑器

此 Skill 自带完整本机浏览器编辑器，无需复制其他项目或安装前端依赖。需要 Python 3.9+ 和浏览器，数据留在当前项目，默认按 Codex 会话隔离。

## 启动

以当前任务的实际项目目录作为 `--project`，不可把本 Skill 所在目录当成用户项目。解析符号链接后以实际目录隔离数据。

```sh
python3 /绝对路径/vector-editor/scripts/launch.py --project /绝对路径/当前项目 --open
```

这里的 Skill 路径使用本文件所在目录，不要照抄占位路径。通过可保持运行的命令会话启动；程序前台运行，输出本次 URL 和保存位置。画布默认在系统浏览器中通过本机 HTTP 端口打开，启动带 `--open`；用户指定其他浏览器时遵照其选择。默认自动选择端口，只复用项目、工作区身份、保存目录和版本均一致的服务。打开输出的完整 `http://127.0.0.1:<端口>` URL，保留共享地址中的 `?client=...`，不能默认使用其他会话或项目已开的 8767 页面。工具仅监听 `127.0.0.1`，不创建登录启动项。

## 状态栏与维护发布

macOS 状态栏通过 `scripts/menubar.py --project 当前项目` 启动，管理编辑器列表、新建、改名、关闭移除及退出；画布仍在浏览器中按完整端口 URL 打开。页面可用 `--name 名称` 命名，`--blank` 创建空白工作区；名称不改变保存位置。

底部“退出”左侧的“重新启动”重启本机登记的编辑服务，也恢复意外停止的服务。保持原项目、工作区、端口、作品 ID 和共享 client 地址，不刷新浏览器画布或写入作品；不恢复已隐藏/移除的作品。重启期间显示进度并防止重复点击；原端口被其他服务占用时报告失败，不换端口。完成后更新列表，失败项可重试。“退出”仍仅退出状态栏应用。

列表按最近实际编辑时间倒序，普通心跳、打开页面、刷新或改名不会置顶。名称、项目和 ID 统一左对齐，条目交替底色；名称用深色文字，悬停高亮，右侧图标可打开页面，名称后标注 `[正式]` / `[测试]`。每个作品工作区有固定 `drawingId`（如 `图-12ab34cd56ef`），状态栏可复制，页面顶部也显示；改名、服务换端口及共享工作区不同 client 均不改变 ID。保存给 AI 和另存为副本携带此 ID，但在另一工作区打开副本不会改变目标工作区的 ID。

点击名称或打开图标时，优先切换已运行的 Chrome、Safari、Edge、Brave 中相同完整地址的标签页，没有匹配才交给默认浏览器新开。根地址末尾有无斜杠等价，端口、主机及 client 参数保持区分。首次使用可能需要 macOS 自动化授权；检查失败时提示原因，不把无法检查误判为没有页面。

用户给出作品名称或固定 ID 时，先用 `python3 此Skill目录/assets/editor/manager.py lookup --query "名称或ID"` 查找。返回 `editors` 含当前名称、`drawingId`、完整 URL、项目、工作区和保存目录。`ambiguous: true` 表示不同作品同名，必须让用户以 ID 明确目标，不能擅选；同一共享作品多个 client 不算不同作品，沿用用户指定的完整地址。再按目标的 `saves` 读取 `latest.txt`；这只代表“保存给 AI”的版本，不能把未手动保存的浏览器草稿说成最新 AI 文件。`list` 可查看全部当前条目。默认是正式版；AI 测试必须设置 `CURVE_EDITOR_EDITION=test`，使用临时项目和 `--port 0`，测试记录、自动端口和作品目录与正式版隔离，不占正式端口 8767—8866。

维护源码时，在独立源码项目修改并验证相应行为；验证通过后自动发布到共用 Skill，运行该项目的 `tools/curve-editor/install_skill.py` 并核对已安装文件一致，无需再次询问。状态栏源码变更时同步重建已安装应用。

默认会话身份依次取 `CODEX_THREAD_ID`、`CODEX_SESSION_ID`；同一会话重开恢复自己的作品，不同会话的画布、操作记录、保存文件和 latest 指针分开。可用 `--session 实际会话ID` 显式指定；不要把其他聊天的 ID 当作当前会话。没有环境身份时每次启动创建新 ID，可从本次 `/api/health` 的 `workspace.id` 读取，后续用 `--session` 重开。

用户要求会话共享时，在同一项目使用相同的共享名称，例如：

```sh
python3 /绝对路径/vector-editor/scripts/launch.py --project /绝对路径/当前项目 --shared "协作稿" --open
```

共享名称由用户指定，或根据任务选一个稳定名称并告知用户；其他会话使用同一名称即可接续“保存给 AI”的最新作品。共享是保存后接续，不是实时同步；每个成员保留自己的未保存草稿和操作记录，已有未保存修改时重开会保留草稿并提示共享已有新保存。本地导入或仅“另存为”的作品也优先恢复；当前画布已保存到共享工作区且没有后续修改时，自动接续其他成员的最新保存，未修改的初始练习画布也会接续首个共享保存。同一成员打开相同地址的多个标签页仍共享该成员的恢复记录，不应同时编辑。若要将已有独立作品转入共享工作区，先在原页面保存，再在共享页面“打开修改”导入那份实际 JSON 并保存，不覆盖原页面。

旧版项目存档通过 `--shared default` 访问，仍使用原 `sessions/` 根目录；普通新会话不会自动读入旧版或其他会话的作品。页面顶部显示“独立会话”或共享工作区名称；通过 `/api/health` 的 `workspace` 与 `saves` 确认身份和实际保存目录。旧服务没有工作区身份时视为旧版项目共享，不得描述为会话隔离。

同一浏览器、同一个完整地址（共享地址须保留相同的 `client`）打开的多个标签页，A 编辑并显示“已保存在本机 · 刷新可恢复”后，B 刷新会接续最新画布和完整操作记录，包括撤销/重做位置，无需另点“保存给 AI”。旧页仅刷新、关闭或调整视图不会回写覆盖新作品；不实时替换其他已打开页面。两页分别改动形成分支时，在本机保留被替换分支；旧格式恢复记录原样保留，并备份升级期间发现的不同旧版本。首次从不支持同步的旧版升级，先刷新当前内容正确的页面，再刷新其他相同地址的页面；全部载入新版后再继续编辑。分别创建的同名页面仍可能是独立工作区，不能按名称判断同步。

已有画布可能含未保存修改；打开另一份作品或刷新前，先通过“保存给 AI”保存当前作品。不要用示例覆盖用户作品。工具更新后先保存旧页面，再重新启动；旧服务缺少新版能力时会另开端口，保留旧页面。

## 生成、导入与修改

- **快捷选色**：功能面板“当前曲线”提供与拟合一致的 20 个常用色块，点击立即修改所选曲线，多选可一起改色，并保留自定义线色、撤销/重做和本机恢复。以后所有新增或修改的选色入口都应提供常用色快捷选择。

- **点位标注**：点左侧“点位标注”后点击曲线或节点，或右键位置选“添加点位标注…”，输入 1–32 位英文字母和数字，如 `01`、`A1`。圆点、短引线和文字默认保存在“位置标注”图层，取消不建层；隐藏或锁定该层时提示先显示解锁。双击可修改内容和字号，可移动、等比缩放、旋转、删除并撤销重做；JSON、本机恢复和 SVG 均保留。标注模式持续显示可见曲线的节点，创建后可连续点击下一个位置；Esc 回到节点工具，V 切换选取。标注关联创建时的曲线，随整条曲线移动、缩放和旋转，旋转时文字保持水平正向；同时选中曲线和标注也只变换一次。标注记住对应节点或曲线段落点：单独拖动节点、调整控制柄和改变曲线形状时实时跟随，文字与点位的间距保持且文字水平正向。增删节点后在所属曲线内重定位，断开曲线时关联分配到对应片段；撤销、重做与本机恢复保留关联。AI/DXF 将文字、圆点和引线转为轮廓线，打印选中曲线不含标注。

- **打印选中曲线**：选择一条或 Shift 多选，点顶部/曲线右键“打印选中曲线…”，或按 ⌘ / Ctrl + P。先完成两点标定，打印按真实 mm/cm 比例换算，与视图缩放无关。支持 A4/A3 横竖方向，超页自动分页，拼接重叠 5 mm；只打印所选可见曲线，输出黑色线稿并保留虚线，不含底图、文字、节点和辅助线。浏览器打印窗口选相同纸张和方向，缩放设 100% / 实际大小，关闭适合纸张及页眉页脚；纸上 50 mm 校验线用于量尺核对。打印与取消不修改作品、标定或操作记录。
- **节点右键菜单**：字号和行距紧凑，仅显示当前选中节点可用的编辑操作；单个开放端点才显示“继续画线”，可断开的单节点才显示“断开连接”，连续多节点才显示圆顺或“设为剪口”操作，已有剪口才显示“取消剪口”。导入图片、创建文字、打印及整条曲线操作在画布或曲线菜单使用；已选节点时在空白处右键仍编辑该选区。矮窗口中菜单滚动不会关闭，支持方向键选择。
- **节点颜色**：用节点工具单选、框选或 Shift 多选节点，在“曲线与节点 → 节点颜色”点常用色块即可改色，也可点自定义颜色；右键“设置节点颜色…”能直接打开入口。“清除颜色”恢复普通节点显示。已着色点在取消选择后仍显示，拟合时原位置与随动位置保持同色，剪口节点使用剪口自身的刚性变换；局部拟合只显示选区内的随动点。颜色随 JSON 和本机记录保存，支持撤销/重做，修改颜色不改变几何或曲线线色。节点定位圆点不额外导出为 AI/DXF/SVG 线条。
- **增加剪口**：在普通曲线或节点所需位置右键“增加剪口”，自动生成口宽与深度 1:1 的 V 形并标记。按曲线长边 1.5% 定尺寸，已标定时常规限制 0.8–3 mm；端点附近、已有剪口附近及狭窄处继续缩小。闭合轮廓朝内，开放曲线朝节点方向左侧；精确开放端点、已有剪口内部、未解除的对称关联和空间不足时拒绝且不改图。拟合预览先展开再添加。剪口外侧保留原贝塞尔曲线，支持一次撤销/重做、本机恢复与 AI/DXF/SVG 实际线稿导出。
- **设为剪口**：先用节点工具点选轮廓，再从空白处框住剪口两端和尖点（至少 3 个连续节点），点顶部“设为剪口”，也可右键同名操作。标记变橙色，不改变原坐标；选中剪口任意节点后“取消剪口”只去掉标记。再框选包含剪口的连续缝边，点“局部拟合”、点另一片的边，直接拖橙色剪口，最后“展开并保留修改”。拟合按开口跨过去的临时缝边计算长度，剪口自身完整旋转、平移，宽深和控制柄形状保持。普通范围切入剪口会自动包含整个剪口；直接点选剪口尖点或内部节点作为拟合起终点时，使用它在口部缝边上的投影位置计长，不把凹口绕行长度算入；边界剪口也完整保持宽深和控制柄形状，只作平移、旋转，不拉伸。该边界剪口在拟合视图中仍不可单独改形或加点。连续对合/回撤、拖动取消、撤销/重做和 JSON/本机记录恢复均保留标记。整片模式下，选段外的剪口保持形状随动，但须扩大对合范围后才能拖动。“编辑拟合曲线”中不单独编辑受保护的剪口点；可在原图修改剪口形状，拟合预览随之更新并保持新形状。
- **拟合性能与界面清理**：沿轨道移动复用同一份原曲线映射计算，改变起终点或重建拟合时使用新的映射；缓存有数量上限，不改变几何精度和展开校验。已移除不展示的旧三步提示、旧图示和未实现的立体弯曲占位，保留点选、换侧、剪口、原图/拟合编辑及撤销功能。
- **拟合快捷操作与对比**：每次进入拟合自动展开快捷浮窗，即使上次最小化过；四个起终点按钮立即可用，无需预选整条曲线：点按钮后直接点节点，第一点确定所属曲线，另一端必须在同一条曲线上；原曲线和目标曲线均选好两端后对合，先选目标或先选终点也支持。成功点选后自动按“原曲线起点 → 原曲线终点 → 目标曲线起点 → 目标曲线终点”切换，按钮高亮下一步；无效点选不会推进，仍可手动切换步骤或先选终点。未选齐时标出已选端点，点击起点可重新选其他曲线。画布浮窗提供“原曲线：设起点 / 设终点”和“目标曲线：设起点 / 设终点”，点按钮后再点对应曲线任意节点；当前操作按钮高亮，右侧面板入口同步。原曲线和目标曲线为闭合轮廓时，各自下方单独一行提供“换另一侧绕行”，侧栏同步提供入口，保留已选起终点，切换另一侧路径。目标换侧后固定当前两端，后续调整原曲线范围也保留目标两端。拟合范围高亮跨过已标记剪口的口部直连，与缝边计算一致；剪口原始轮廓仍用细线保留。目标曲线明确设过终点后，修改原曲线范围或原节点仍保留该终点；继续对合到指定目标终点时提示先调整终点。长度不同时显示差值，不拉伸原曲线。浮窗和侧栏的“隐藏拟合曲线 / 显示拟合曲线”控制拟合后的移动副本，包括剪口、节点和定位控件；未拟合原图、固定目标轨道和其他曲线保留。隐藏时退出拟合节点编辑，选择起终点不会自动显示；进入“编辑拟合曲线”时恢复显示。只影响当前预览，不修改图层或保存内容。起点使用小圆点、终点使用小方点，沿线箭头标明方向；节点及金色定位点缩小显示，但保留较大的透明点击区域，分数位置的端点中心也可直接点击换起点。拖动浮窗顶部标题栏（⠿）可移动位置，展开和最小化状态分别记住位置；窗口缩小时保持在画布可见范围内，拖动中按 Esc 取消移动。浮窗只能最小化，不能关闭；点击最小化条或右侧入口可恢复。原曲线和目标曲线旁均可直接打开选色面板，提供常用色块、二维饱和度/亮度色板、色相和十六进制颜色代码；颜色立即同步画布与右侧面板并记住偏好，不改作品颜色或操作历史。
- **局部拟合**：选中一条原曲线后，点左侧“局部拟合”或按 N，再点另一片要贴合的边；想只拟合一部分，先用节点工具框选连续几个点或按 Shift 加选，再按 N。没有预选时仍可依次点两条边。进入拟合后，默认单击原曲线任意节点设为拟合起点；点右侧“点选终点”后，再单击任意节点设终点，修改一端保留另一端。选轨道前后都可调整。开放曲线按起点到终点确定方向；闭合曲线可跨首节点，“换另一侧绕行”切换两端之间的另一段。切换“编辑节点”可恢复普通节点选择和精细拖动。原曲线端点标记周围仍可一键反向，拖中心节点仍修改原图。修改原曲线范围保留轨道起点和对合位置。贴合轨道上的所有节点均可直接单击设为对合起点，首次选轨道时也可直接点节点；重新按原曲线所选长度对合，对合位置归零，原曲线起点不变。中间节点沿当前方向，开放轨道到头时自动向内；闭合轨道可跨原首节点连续对合。原图节点工具下拖动仍修改节点，轻微点击抖动不会移动节点；锁定轨道可选起点但不移动节点。剪口内部节点作为起点时，按口部缝边上的投影位置对合，内部冗余节点不按数量均分位置；所有已标记剪口统一按缝边基线计长，原剪口几何不变。未标记的凹口不会自动猜测为剪口。贴合轨道选定范围的两端也有小标记，点击端点标记周围可设为轨道起点，并把对合位置移回该端（对合位置归零），沿箭头方向重新对合；原曲线起点保持不变。实心小圆点标记轨道起点，另一端标为轨道终点；移动金色点后，轨道端点保持原位，“对合起点”跟随实际位置。实心小圆点与“拟合起点”标记当前起点，另一端标明“拟合终点”；原选段及对合位置沿线显示方向箭头，“对合起点”标出目标边上的对应位置。这些起点与方向提示始终显示，不受“显示画布文字”开关影响；与“反向原曲线 / 反向轨道”按钮同步，切换不改原节点、长度或保存内容。调整范围时端点控件用于拖动范围；拟合视图增删节点后需先展开再重选起点。点选原曲线起终点、切换绕行侧或轨道起点/方向会重新开始连续对合的回退记录，已有曲线修改保留。只把选中的连续段及该范围内的短剪口弯过去，未选轮廓和选区外剪口留在原位，原曲线不拆断；支持闭合轮廓跨起点选择，不连续或跨曲线的选择会提示重选。直接拖橙色剪口可整体移动并保持长度，点“展开并保留修改”带回原形，未修改节点和控制柄保持原坐标。对合完成后默认可直接编辑原图：F10 拖原节点/控制柄、双击加点、Delete 删点，拟合与长度实时重算；B 可画线，也能在其他曲线标记、改形状、使用右键和图层面板。原图修改可撤销/重做且保留拟合；原图增删点会跟踪原选段。若要直接修改弯曲后的预览，点“编辑拟合曲线”，局部两端灰点固定，内部节点、控制柄可编辑，双击加点、Delete 删除内部点；增删后先展开再重选范围。也可直接点一段边开始；“继续对合下一段”或“调整对合范围”用于扩展连续范围。连续对合后可点“退回上一段”逐步回撤范围，保留剪口和曲线修改；左上撤销/重做及 Cmd/Ctrl+Z、Cmd/Ctrl+Shift+Z、Ctrl+Y 支持最近的继续对合操作，新继续会清除已回退的重做分支。若之后实际编辑了剪口或节点，普通撤销仍优先撤销该编辑；只想缩回对合范围时用“退回上一段”。范围记录只在本次拟合中保留，展开后不占作品撤销步骤。画布快捷操作右上角“—”可最小化，保留可点击的恢复入口，不提供关闭按钮；也可在右侧点“显示画布提示”恢复，最小化不退出拟合或修改作品。拟合面板可分别点“原曲线 / 拟合线”和“贴合轨道”的色块即时换色，当前浏览器会记住选择；只改变预览，不修改纸样原有线色。原曲线按所选颜色持续高亮，粗线标出所选范围。画布文字默认隐藏，原曲线和轨道名称显示在右侧，金色定位点保留悬停提示；需要时勾选“显示画布文字”。拖金色对合点时只移动定位点并显示预计落点；松手后曲线和剪口沿固定轨道按弧长滑动，能继续转过后续弯道及闭合起点，不拉长纸样。点击、切换操作或展开会停止移动，取消拖点保持原位置。滑条可直接调整位置，反向按钮切换方向。“更多调整”中的“整片随动”默认关闭，需要时手动开启。缝边按真实弧长映射，不缩放；整片二维随动仅作示意，不可靠的重叠位置拒绝编辑。预览失败保留原线和已有修改。保存、导出与本机记录始终使用展开数据。
- **拟合中修改与展开**：原图编辑默认可用，改原曲线或贴合轨道时实时更新拟合；B 在预览位置画出的新标记按实际画布坐标保留，不自动反算到原曲线。直接编辑弯曲视图时，先点“编辑拟合曲线”；拖动金色对合点或右侧滑条调整对合位置，点击活动曲线后拖节点/控制柄，双击加点，Delete 删除所选点，方向键微调。原形作为底稿，只把实际编辑映射回原坐标；“展开并保留修改”或 Esc 退出，未修改部分原坐标完全保留，主动加长、改短或增删点也保留。修改继续支持自动记录、保存、导出与撤销，保存/导出始终使用展开纸样。Esc 发生在拖动中时仅取消该次手势。弯曲重叠、局部折叠或反向映射不可靠时拒绝修改并提示调整范围。立体弯曲标为“待实现”，当前不提供布料物理模拟。


- 左侧工具栏贯穿窗口全高，使用紧凑图标和文字，无滚动条；文件操作、画布及属性面板位于右侧。拖动左栏右边缘调宽，达到 132 px 自动排成两列，收窄恢复单列，矮窗口自动提供双列空间。双击边缘或聚焦后按 Home 恢复默认，← / → 调宽，Esc 取消拖动。宽度和折叠状态在浏览器记住，保持作品、缩放和画布中心，不进入撤销历史。
- “矩形”（R）和“椭圆”（E）：选中可编辑普通图层后拖动绘制，松开生成闭合曲线，可连续绘制；按 F10 编辑节点。拖动显示宽高，接近正方形或圆形（宽高差不超过长边 5%）时绿色提示，普通拖动不强制吸附；按住 Shift 约束等宽高，松开恢复自由比例。Esc、切换工具或失去焦点取消预览；不留下空曲线或撤销记录。每个形状可一步撤销/重做，沿用图层可见/锁定和 JSON、AI/DXF/SVG 保存导出。椭圆/圆为四段三次贝塞尔近似，标准 kappa 的归一化半径最大误差约 0.0273%；DXF 的 0.01 mm 输出近似误差以该贝塞尔曲线为基准。未标定显示 px，不猜测实际尺寸。
- 右侧功能面板可拖动左边缘调宽；展开图层、属性、曲线、测量等功能组后，拖动组底部横条调高，过长内容在组内滚动。拖动功能组标题上下换序，Alt + ↑ / ↓ 可用键盘换序，收起右栏后的图标沿用新顺序；点击标题折叠/展开。双击尺寸拖拽条或聚焦后按 Home 恢复默认，方向键调整尺寸，Esc 取消当前尺寸拖拽。窄屏只调高度；浏览器记住排列位置、折叠、尺寸和侧栏/组内滚动位置，刷新后恢复，不写入作品、不占撤销历史。
- PNG/JPG/WebP：用“导入图片”，或拖入、粘贴图片；在当前画板新增图片图层，不替换已有作品或清除标定。图层可命名、隐藏、锁定、排序和删除；图层面板加号左边的眼睛按钮可显示/隐藏全部图层（含锁定层），部分可见时点击显示全部；一步撤销/重做。眼睛前的复选框全选图层，取消勾选清空选择，部分选中时显示半选状态；包含折叠组的子层、隐藏层及锁定层，只有可见且未锁定的内容参与画布编辑，选择本身不占撤销记录。旧底图转为锁定图层，可解锁。图片仍是位图，不能拖节点改轮廓。
- **图片实际尺寸**：粘贴、导入或拖入 PNG/JPG/WebP 时读取图片实际携带的 DPI（PNG pHYs、JPEG JFIF/EXIF、WebP EXIF），按毫米尺寸换算到当前画布；支持横纵 DPI 不同及 EXIF 方向。已有标定保持不变；空白未标定画布自动采用图片比例，图片与比例可一步撤销/重做。有旧内容但未标定时，暂存带 DPI 的图片，先标定原画布，应用后继续；取消、切换作品或撤销会取消待导入。缺失、无单位或无效 DPI 时直接按像素放入，不提示标定。macOS 真实粘贴时由本机服务补读系统剪贴板中的 PNG/JPEG/TIFF 尺寸，逐像素核对与浏览器粘贴图片相同后才采用；已实测“预览 → Chrome”可恢复被浏览器去掉的 DPI。补读仅发生在本次粘贴，不后台监视，不上传；剪贴板无尺寸、内容不匹配或读取失败时直接按原有方式粘贴。用户确认的扫描默认规则：没有有效 DPI 时，像素恰好为 826 × 1168 或旋转后的 1168 × 826，按 100 DPI（1 px = 0.254 mm）换算，并提示“扫描默认 DPI 100”；有效文件/系统剪贴板 DPI 优先，其他尺寸保持普通像素粘贴。该规则用于之后导入、拖入或粘贴，不追溯改变已有图片。DPI 只表示文件记录的比例，不保证扫描时未经过缩放。
- **曲线锁定**：展开图层后，点曲线右侧的锁按钮可单独锁定/解锁。锁定后不能选中拖动、修改节点/控制柄、缩放或删除该曲线；锁定开关会结束当前拟合预览，已完成的修改保留。点击所属图层、图层组或多选图层，仍可用圆柄或角度输入一起旋转，包含锁定曲线，曲线锁定状态保持；隐藏内容和锁定图层/祖先组不参与旋转。支持撤销/重做、JSON 和本机自动恢复。
- 图层多选后可“成组”“解组”或“合并”（面板按钮或右键）。Shift 或 Cmd/Ctrl 点击图层名称多选；成组和合并要求同组内相邻图层，以保留与其他图层的叠放关系。组可折叠、嵌套、命名、排序、隐藏、锁定、删除，单选普通层、组或多选任意图层可整体移动、缩放和旋转；选子图层继续编辑。解组保留内容和有效显示/锁定状态。合并归属保留独立曲线、节点、控制柄、图片、文字与混合绘制顺序，不连接曲线或生成位图；显示/锁定状态不一致时提示先统一。操作可一步撤销重做，并随 JSON、操作记录副本和刷新恢复。
- 右键图层“置顶”一次移到最上层，之后仍可拖动排序，新建图层也可放在其上方；已在最上层时禁用。保留可见性、锁定状态和内容，支持一步撤销/重做及保存恢复。
- “提取线条”（T）：在图片上悬停，按颜色容差、连接距离和平滑程度跟踪局部线条；实线或虚线均以蓝色预览，点击后生成节点与控制柄仍可编辑的曲线。来源图片保留，处理只在本机进行，不调用大模型。颜色混杂、遮挡或边界不清的区域可能提前停止，应分段提取或手工补线；虚线只是连续几何的显示样式。此功能辅助描线，不应描述为可全自动提取任意照片。
- “提取外轮廓”（Shift + T）：指向物体内部或外边缘，预览完整外框；点击或 Enter 生成闭合可编辑曲线，Esc 取消。适合背景简单、边缘清楚的实物照片及透明图片，保留凹口并忽略内部纹理和孔洞；分离物体按鼠标位置分别提取。背景容差、去毛边与拟合误差独立于线条模式；增大容差可排除浅色阴影。去毛边默认 8 px（0 关闭），先滤掉细小突出和缺口、平滑主体走势，再进行有误差约束的贝塞尔拟合；拟合误差默认 2 px，相对去毛边后的轮廓计算，越小越贴合，越大节点越少。两项均按原图像素计算，只影响新提取；过强去毛边可能抹去真实细节、断开细颈，应对照预览；断开时选择鼠标所在部分。保留来源图片，支持撤销重做、保存及移动缩放后的图片；本机处理，不调用大模型。照片边缘应留有足够背景；复杂背景或模糊边缘需要人工修整。
- 文字工具（F8）在画布点击创建文字，可输入多行内容，并在属性区调整内容和字号。新文字默认进入“文字图层”，不存在时在确认创建文字后自动新建，取消不留下空层；已有文字编辑时保留所属图层。文字随图层隐藏、锁定、排序、删除和保存；可移动到画板外，SVG 导出会扩展范围避免裁切。保存格式与限制见 [曲线格式](references/curve-format.md)。
- **更换所属图层**：在图层列表中拖动文字、曲线或图片到目标普通图层名称（折叠时也可接收），或拖到目标图层已展开的内容区域；已选元素支持一起移动，未选元素拖动时仅移动自身，成功后展开目标图层。同层曲线仍可拖动上下排序，Esc 或放到画布空白处取消。也可选中文字、曲线或图片后，在“对象属性 → 所属图层”选择目标普通图层，可一次移动跨图层的多种元素。保留内容、坐标、节点和控制柄，移入目标已有内容上方，支持一步撤销/重做、保存和刷新恢复；隐藏、锁定图层及其子层不能作为目标，图层组须选择其中的普通图层。
- 曲线列表选中一条或多条曲线后，可直接拖动曲线或选框内部整体移动，方向键微调、Shift 方向键移动 10 px。选框上方圆柄默认绕共同外框中心旋转，Shift 按 15° 吸附；放大或平移使圆柄超出画布时，圆柄自动移到可视区域内，仍绕当前旋转中心旋转，无需缩小视图；拖动角度显示最多两位小数；“位置与尺寸”的“旋转角度”输入本次相对角度，正数顺时针、负数逆时针，再点“应用旋转”或 Enter。节点和控制柄一起变换，移动、旋转后保持选中，一次操作一步撤销/重做并保留选择；节点工具选中节点后继续编辑节点。图片沿用同一旋转圆柄和角度输入，可与曲线混选后一起旋转；文字也支持旋转，旋转后仍可修改内容和字号；点击单个普通图层会选中层内可编辑内容，Shift 或 Cmd/Ctrl 可增减任意图层，共同绕当前旋转中心旋转，单独锁定的曲线随图层旋转，隐藏内容和锁定图层不参与。图片默认绕自身或共同选框中心旋转，保留原始图片，旋转后可继续移动、等比缩放及提取线条/外轮廓；已旋转图片的宽高输入自动保持比例。旋转角度随 JSON、撤销重做及刷新恢复保存。
- **自定义旋转中心**：选中整条曲线、图片、文字或多个图层，拖动画布上的橙色十字圆心到任意位置，再拖蓝色旋转圆柄或输入角度，两种方式均绕同一中心旋转。拖动中心时显示可见曲线节点，接近 9 个屏幕像素内自动吸附并变绿；锁定可见曲线也可参考，隐藏曲线不参与。Alt 暂停吸附，Esc 取消本次中心拖动。对象属性 → 位置与尺寸 →“恢复选框中心”恢复默认。自定义中心在同组选区中保持画布坐标，更换元素选区会重置；节点工具中重合处优先编辑曲线节点，按 V 切到选取工具可拖动重合处的中心。中心设置不改变作品、不占撤销步骤，也不清除重做；本机恢复及含操作记录的副本保留中心设置，AI/DXF/SVG 不导出辅助标记。
- 选取工具可移动图片或曲线、拖角等比缩放；节点工具中从曲线列表选中整条曲线时，也显示四角缩放柄，拖角保持比例并支持撤销恢复；选中具体节点或线段时保留节点编辑，不显示整条曲线缩放柄。也可在“位置与尺寸”输入像素位置和宽高。“缩放倍数”输入 2 放大到当前尺寸的两倍，0.5 缩小到一半，点击“等比缩放”或按 Enter 应用；始终围绕所选内容共同选框中心等比缩放，不受宽高比例勾选影响，支持曲线、图片、文字及多选图层，保留节点和控制柄，可一步撤销/重做。仅接受大于零的有效倍数，应用后回到 1；标定比例不变，导出实际尺寸同步缩放。勾选“保留原曲线（生成缩放副本）”后，在各自原图层生成并选中缩放副本，原件不变；混选的图片、文字同样保留原件。缩放后的曲线自动换色，优先使用画布中未占用的颜色，颜色随撤销/重做、保存和刷新恢复。空白处框选，Shift 点击多选；全选排除隐藏和锁定图层。新曲线画在当前图层，同层图片位于曲线下面。图层和图片变换随 JSON 保存，支持撤销重做。
- 节点或选取工具点击画布中的曲线、节点、控制柄、图片或文字，会自动选中所属图层，已选元素也可定位并保留多选和编辑状态；可见锁定内容仅定位，不能编辑。创建曲线及提取工具保留当前目标图层；新文字自动使用“文字图层”。
- 所有画布工具可按住 Ctrl 或空格临时平移，松开恢复原工具与编辑状态；节点、控制柄、整条曲线、缩放和旋转拖动中可暂停改形、平移画布，再继续原拖动。选段、多选、未完成曲线和撤销历史保留；输入框的快捷键照常使用。
- 节点工具（F10）点击两节点之间的线，蓝色高亮后 Cmd/Ctrl+C（工具栏“复制”或右键“复制线段”）只复制本段。Cmd/Ctrl+V 粘贴成独立的开放曲线，保留原坐标、弧度、线型与本段控制柄，并自动换成不同颜色；可先点击目标图层再粘贴，副本自动选中，可直接拖走。原曲线不变，支持闭合曲线末段、一步撤销/重做和保存恢复。曲线列表选中后复制仍为完整曲线。
- **元素复制粘贴**：选中曲线、图片、文字、点位或尺寸标注后按 Cmd/Ctrl+C（或工具栏“复制”），点击目标图层，把鼠标移到画布落点，按 Cmd/Ctrl+V。整组选中元素的轴对齐包围框左上角对齐鼠标，旋转图片和文字按旋转后的范围计算，元素间相对位置与叠放顺序保留。工具栏“粘贴”和右键“粘贴元素”沿用鼠标最后停留的画布位置；尚未进入画布时用视野中央。曲线保留节点、控制柄、闭合、虚线与备注，副本换线色；图片保留内容、透明度和旋转，文字保留内容、字号和旋转。同批复制的标注关联到新曲线，单独复制标注不会继续绑定原曲线。支持一步撤销/重做及本机恢复；目标必须是显示且未锁定的普通图层。选中的页面名称、ID 和输入框文字仍按普通文字复制。跨页面、端口和项目粘贴使用同一本机、同一正式/测试类别最近主动复制的元素，无需读取系统剪贴板权限。复制时携带实际比例，粘贴时按目标标定换算曲线、图片、字号与标注，保持物理大小；空白目标采用来源比例，已有内容但未标定的目标先标定，再粘贴到原先图层和落点；未标定来源只允许本页按像素粘贴，跨页必须先标定。复制后等待“可跨页面粘贴”；旧页面请刷新后重新复制。其他应用的图片用 Cmd/Ctrl+V，图片左上角同样对齐鼠标，并放入新图片图层。
- 选中节点后按 J，在直线节点与平滑节点之间切换：所选均为直线节点时转为平滑，否则统一收起手柄转为直线。支持跨曲线多选及一步撤销/重做，不改变新节点默认类型；输入文字时不触发。“收起手柄 · 直线节点”按钮显示 J 提示，点击仍只收起手柄。
- 节点工具点选两个节点之间的线段，蓝色高亮后按 J 切换直线段 / 曲线段，只改变本段两端对应的手柄，相邻线段保持原形。端点转为尖角类型，两侧独立，支持一侧直线、一侧曲线；两端手柄都可拖动调整本段。直线转曲线生成可编辑手柄，共线时外观可保持直线，再拖动调弧度。闭合曲线末段、一步撤销/重做、刷新及含历史副本恢复均支持；点击节点返回整个节点的 J 切换。
- 节点工具（F10）先选中一条曲线，再框选时只选择本曲线节点，不会混入重叠副本；未选曲线或已选多条时可跨曲线框选，Shift 框选追加，Esc 清空。框选节点后，右键“顺滑所选节点”按相邻节点走向重新计算控制柄，让连线转折更圆润；在所选节点、连线或空白处右键均可操作。保持节点位置、数量和未选节点，支持跨曲线多选及闭合曲线，一步撤销/重做，不改变新节点默认类型。共线节点仍保持直线；重合点和原路折返处不强行制造弧度。
- “整段圆顺…”：F10 在同一曲线选择 3–200 个连续节点，再用右键或节点面板按钮打开。首尾位置固定，中间点默认可微调；勾选“必须经过”锁定任意中间点。按允许偏差整体计算平顺曲线，整段（包括节点间）相对原曲线的偏离有上限；标定后可用 mm/cm/px，未标定仅 px。绿色为预览，金色实心点固定，绿色空心点可调整，编号对应原曲线；预览时可滚轮缩放、直接拖动画布平移及使用顶部缩放/适合窗口，其他编辑暂时停用；取消/Esc/预览中刷新不改作品，点击应用后可一步撤销/重做。保留节点数量、顺序、端点原有切线方向及外侧手柄，未选线段不变；闭合曲线只支持局部连续跨度（可跨末段），不能整圈或跨多条选择。限制太小或必经点不相容时提示调整，不能保证任意容差下均有可行结果，不自动放宽限制。
- 每个普通图层下直接列出文字内容、曲线和图片，默认折叠，点击图层左侧箭头展开；展开/折叠不占撤销记录。每行眼睛可单独显示／隐藏曲线，隐藏后保留列表条目，便于重新显示；隐藏曲线不参与选择、编辑、测量及 SVG 导出，不影响同层其他曲线。曲线列表双击名称可重命名，失焦或 Enter 确认，Esc 取消，空名称保留原名；拖动条目上下换序，蓝线提示插入位置。可见性、命名和排序可撤销重做，随作品保存；保留图层归属与节点坐标，隐藏图层仍可展开查看内容，但元素不可编辑；重新显示图层时保留各曲线自己的可见性；锁定图层曲线仍列出但不可编辑或切换可见性。图层列表双击名称也可重命名，沿用失焦/Enter 确认及 Esc 取消。中文输入法选字时 Enter 不提前确认。
- 节点工具选中开放曲线的单个端点，右键“继续画线”，从该端点接着绘制；首端和末端都支持。点击加点、拖动拉出手柄，点回本曲线另一端可闭合，Enter / Esc 结束。保留原有线段、节点、控制柄、样式及图层，新增节点可逐步撤销/重做，刷新及含历史副本恢复续画方向；闭合曲线和内部节点不可直接续画。
- 节点工具选中闭合曲线任意节点或开放曲线内部节点，点顶部或右键“断开连接”：闭合曲线在该点展开，开放曲线分为两条，原有贝塞尔弧线保留。断口两端起初重合，直接拖动当前端点即可分开。单个开放端点靠近另一可编辑开放端点（3 个屏幕像素内），绿色提示松开选择连接或仅重合；靠近自身另一端可选择闭合，闭合后至少保留三个节点。松开后弹出“连接节点 / 仅保持重合”，默认聚焦仅重合；Esc、点击别处或切换窗口也保持两个独立端点，坐标精确重合，可分别拖开。只有确认连接才合并为一个节点，跨曲线连接继承拖动曲线的名称、样式和图层；Alt 暂停吸附连接。按 V 单选并拖动整条开放曲线也可连接；节点工具从曲线列表单选后拖动，或仅选中该曲线全部节点后拖动同样支持。节点和控制柄整体平移保持原形，多处端点进入 3 像素范围时，只提示并询问最近的一对，确认连接后保持整条曲线选中；有效端点连接优先于普通节点对准。部分节点、多条曲线、图片/文字混选或控制柄拖动不连接，隐藏/锁定内容不能连接。断开、拖动后选择连接或仅重合均支持一步撤销/重做及 JSON 保存、刷新恢复；菜单打开时也自动记录移动，未选择就刷新将恢复为独立重合端点及原有撤销记录。
- **重合的端点改为连接**：框选或多选至少两条可编辑曲线后，在画布、节点或曲线列表右键使用。按所选完整曲线处理，只连接坐标完全相同的开放端点，保留原弧线和控制柄，不跨空隙补线；多个独立轮廓分别连接，首尾相接且至少三个节点时自动闭合。同一点有三个以上端点时跳过该分叉并提示。隐藏/锁定曲线不参与；每组优先沿用当前主选曲线的样式和图层；主选曲线不在该组时沿用该组第一条。节点位置标记及尺寸标注关联跟随迁移，整次操作可一步撤销/重做及保存恢复。
- 曲线列表按住 Shift 点击多选，再右键所选项“合并曲线”。仅合并至少含两个节点的开放曲线，按最近端点连接，反向时交换控制柄；重合端点合为一个节点，空隙用直线连接，原有曲线段形状不变。沿用最后选中曲线的名称、线色、用途、虚线样式、说明及图层，继续编辑节点或一步撤销/重做；闭合曲线先打开，隐藏/锁定曲线不参与。
- 曲线列表或画板上的曲线右键可“删除曲线”；Shift 多选后在所选曲线上右键“删除所选曲线”，一步撤销/重做并恢复图层归属及选择。右键未选中曲线则仅操作该曲线；隐藏/锁定曲线不参与，节点的“删除这个节点/删除所选节点”仍是独立操作。
- 选中曲线，在画板或曲线列表右键“偏移曲线…”：输入非零正负距离及 mm/cm，闭合轮廓正数外扩、负数内收（如 +5 mm / -5 mm）；开放曲线正数向左、负数向右，左右按起点到终点判断，蓝色箭头标方向、绿色预览新曲线。须先两点标定；未标定时窗口提供入口。所选开放曲线端点间距严格小于 0.01 px 自动拼合成链或闭合轮廓，不跨空隙补线；多个独立轮廓分别处理，混合闭合/开放选择共用同一正负距离。生成新的可编辑曲线并保留原作，继承来源样式和图层，一步撤销/重做；取消、Esc、刷新不保存预览。自交、分叉、过大内收导致消失及结果超限时提示调整，不生成部分结果。极尖角截短尖刺，曲线数值近似后拟合为贝塞尔节点，闭合曲线优先沿用原节点数量拟合，并独立核对整条轮廓的双向偏差，精度不足时才增加节点；预览显示前后节点数，不保证任意形状均能保持原节点数量。可选择自动精度或 0.01 / 0.02 / 0.05 / 0.1 mm 允许偏差，点击“比较不同精度”查看各档节点数，可逐档勾选“一起预览”叠加彩色轮廓，或全选叠加；“设为主方案”切换绿色主预览，只生成主方案，比较和取消不修改作品。所有候选结果均核对双向距离，未通过时收紧拟合或明确提示，生成曲线的说明保留所选允许偏差。本机附带 Clipper 算法及许可，不依赖联网。
- 本工具 JSON：用“打开修改”，可直接编辑节点、控制柄和类型。生成可编辑线稿、转换已有节点或解释保存数据时，读取 [曲线格式](references/curve-format.md)。内置示例在 `assets/editor/examples/心形_可编辑示例.json`。
- “操作记录”支持最近 100 步的逐步预览、自动重放、暂停和速度调整；停止、Esc 或播放结束回到原作品，不改撤销/重做位置。本机浏览器按项目身份保存当前画布、图片和记录，同一浏览器地址刷新可恢复；面板显示保存状态，存储不可用时提示。“另存为…”（Cmd/Ctrl+Shift+S）保存独立 JSON 副本，包含最近 100 步、撤销/重做位置、选择和历史图片；在编辑器内的对话框输入文件名，确认“保存副本”后下载到浏览器的下载位置，可在下载列表查看。用“打开修改”重开副本可继续撤销、重做和重放；记录图片去重，另存为使用紧凑 JSON，含记录文件及“打开修改”的上限均为 256MB。“保存给 AI”（Cmd/Ctrl+S）仅保存当前作品，不含操作记录或历史图片，以减少 AI 读取量；另存为不更新项目 latest.txt。升级前先保存旧页面，旧版本未记录的操作无法补回。
- “打开修改”或拖入 `.ai`/`.dxf` 可打开支持的线稿（最多 16MB），转成可编辑节点，保留图层、闭合与尺寸。AI 按点换算毫米，DXF 按文件单位换算；没有单位的 DXF 必须由用户选择，不能猜测。导入失败/取消保留作品，覆盖未保存作品前会确认。DXF 三次分段贝塞尔样条支持内部三重结点或四重结点（重复连接端点）及混合写法，保留控制柄；断开的分段、一般 B 样条、周期及有理样条仍明确报错。传统 AI、部分 PDF 容器线稿与 CorelDRAW 私有线稿可读；复杂填充、文字/图片、裁剪与透明特效、不支持的 CAD 实体应明确报错，不保证任意 AI/DXF 完整兼容。CDR/PDF 文件入口不直接导入；SVG 仅导出。
- 顶部“导出…”或图层面板/右键的“导出所选图层…”支持 AI/DXF/SVG，每次打开默认 AI。文件名默认使用当前图名加当天日期（如“1号大师版10.18.ai”），导出所选图层也使用图名；可手动修改，切换格式只更换扩展名。所选组包含其可见子层，隐藏内容不导出，锁定可见曲线仍导出；嵌套组以父级名称展开为普通层，DXF 同名层加后缀保留独立。窗口显示曲线总数、原曲线节点数 → 实际导出曲线节点数及毫米宽高，控制柄不算曲线节点；AI 读回核对、DXF/SVG 按真实文件曲线结构统计，切换格式/方式/范围同步更新。文件点另列：DXF 样条控制点/折线顶点，AI/SVG 坐标点总数及其中的控制柄点，含闭合重复点；外部软件再次转换可能改变节点数；AI/DXF 可含文字，导出时转为轮廓线，原文字仍可编辑；SVG 保留文字；含图片须排除。DXF 为带毫米单位的 R2000，可选“折线兼容”或“保留曲线”，打开窗口或切换范围时自动选择实际导出曲线节点数更少的方式（不含控制柄），数量相同选保留曲线；计算完成前暂停导出。前者转为连续折线，近似偏差上限 0.01 mm；后者以三次 SPLINE 保留贝塞尔曲线、控制柄、尖角和闭合段，纯直线路径仍为折线，重新导入本编辑器可继续编辑。对方软件须支持样条，可能显示不同数量的控制点；已有密集折线不会自动还原少节点曲线。AI 为保留贝塞尔的兼容型 Illustrator 线稿；SVG 宽高写入 mm。保留真实比例和曲线相对位置（AI 整体移至原点），不自动加入尺寸标注线、缝份或机器参数。
- 坐标模型仍为 `image-px`；AI/DXF 导入将数值统一为毫米并设置 1 mm/坐标单位的 `calibration`。旧 JSON 或照片描线没有标定时不得声称实际尺寸，导出窗口会引导两点标定。保存给 AI 是 JSON 保存入口，与 AI 文件格式导出不同。

## 镜像与测量

- **关联对称**：镜像面板默认勾选“生成镜像时记住对称关系”，生成时自动记住两侧和当时的轴，无需再次指定。改好一侧后，在该侧线段上右键“以这一侧同步另一侧…”，或 F10 点选该侧线段后用面板同名按钮，预览并应用；节点、控制柄和内部剪口同步，目标曲线样式保留。两侧连接为同一闭合轮廓后仍可使用，不必拆开；增删内部节点可同步。整体变换前点“选中对称两侧”，或选中已合并的轮廓，平移、旋转及等比缩放时关联轴跟随。单独改动一侧不会立即覆盖另一侧，需手动同步。“显示对称轴”只控制辅助线显示，隐藏不解除关联；选中关联曲线时展示它自己的轴，绘制轴工具仍操作独立的绘制轴。点“解除对称关联”保留现有曲线并可撤销；取消生成选项可继续生成普通独立镜像。普通复制粘贴和缩放副本独立，不继承关联。关联和显示状态随 JSON、本机记录、撤销重做保留，不导出到 AI/DXF/SVG。删除关联的另一侧后，可右键“以这一侧重新生成另一侧…”按记住的关联轴预览并生成新镜像，保留当前一侧及图层，支持一步撤销；“生成镜像副本”也可直接按当前绘制轴建立新的关联，无需先手动解除失效关联。旧作品不自动猜测关联；关联被拆散、分界剪口跨两侧或非等比缩放破坏镜像关系时明确提示，不强行同步。

- “对称轴”（A）：点击两点画任意方向的轴，第二点接近水平或竖直 5° 内自动吸附，轴旁显示方向，移开恢复自由方向；靠近节点吸附，接近水平或竖直时优先矫正轴方向，Shift 约束角度。选曲线后点击“生成镜像副本”，或使用曲线右键同名操作；保留原曲线，副本的节点和控制柄仍可编辑，默认记住对称关系。对称轴随 JSON 保存，不导出到 SVG。节点工具（F10）点选线段呈蓝色高亮后，右键“镜像所选片段”（镜像面板按钮同样支持），只镜像本段，生成独立开放曲线并保留原曲线、弧度、样式及图层；闭合末段同样支持，可一步撤销/重做及保存恢复。未设置对称轴时禁用并提示先画轴。 轴画好后，节点、选取、对称轴工具均可直接拖动两端点改变位置和角度，普通拖动可自由微调水平、竖直附近的角度，按住 Shift 约束角度；节点、选取或对称轴工具中点选轴线即高亮，可直接拖动整轴平移（延长线也可选）；方向键微调，Shift 方向键移动 10 px，右键“删除对称轴”或 Delete 仅删除轴，保留原曲线和已有镜像副本。选中轴时保留镜像来源选择，移动实时预览；点击曲线或 Esc 退出轴选择。Shift 拖动约束方向，Alt 暂停自动吸附，Esc 取消本次拖动。先选择一条、多条曲线或所选片段，调整轴时绿色虚线实时预览，预览不写入作品或导出；生成的副本保留；是否关联由“生成镜像时记住对称关系”控制。在对称轴工具中生成副本会保留原对象选择；取消关联选项可继续调整轴并反复生成独立副本。每次拖动支持一步撤销/重做，对称轴随 JSON 与本机自动记录恢复。
- 曲线节点吸附对称轴：拖动节点到轴线或其延长线 3 个屏幕像素内，绿色提示并吸附到轴上；移开脱离，Alt 临时取消。多选节点保持相对位置，取最近节点对准；优先连接可连接端点，普通节点和对称轴取较近目标。Shift 保留约束方向；支持一步撤销/重做和保存恢复。
- **节点吸附曲线与线段提示**：拖动节点到其他可见曲线任意位置的 3 个屏幕像素内，自动吸附并显示绿色提示；按实际贝塞尔曲线计算，支持闭合末段。隐藏内容不参与，锁定的可见曲线可作为参考；移动中的曲线不作为自身吸附目标。多节点共用一次平移，控制柄保持相对位置；Shift 保留方向约束，Alt 暂时取消吸附。端点连接优先，其余节点、轴和曲线取最近目标。拖节点或平移整条曲线时，重合线段绿色高亮；邻近直线段只有完全平行或角度差不超过 0.5°、校正位移不超过 6 个屏幕像素时才提示。接近平行显示“松手对齐”，释放鼠标后自动校正为完全平行；只移动一端时微调节点，两端一起移动时对所选曲线节点与控制柄作小角度刚性旋转，保持选区形状。Shift 保留原方向约束，已有节点/曲线吸附和端点连接优先。Alt 暂停吸附和提示，取消手势不自动校正；每次拖动与校正合为一步撤销，提示不写入作品或导出。
- “测量”（M）→“点距测量”：连续点选位置，显示各段直线距离及累计值；Enter / Esc 结束，下一次点击开始新测量，Backspace 回退一个点。
- 右键“测量整条曲线”显示实际贝塞尔弧长。部分曲线用“选段测量”：点击首段，再 Shift 点击末段，包含首尾及中间连续线段；闭合曲线可切换另一侧。也可右键“从这段开始测量”及“测到这一段（连续选段）”。
- 实际长度：点“两点标定”，在图中点击两个已知距离的位置，填写实际长度并选择 mm/cm，点“应用比例”。所有测量随后按该比例换算，显示单位可在 mm/cm 间切换。标定比例与显示单位随 JSON 保存；新建画板后需重新标定；导入图片保留已有比例，图片是否与画板同一比例需要已知距离核对。没有已知距离时保留 px，不从图片猜测实际尺寸。
- 曲线弧长是数值近似，缩放不改变距离。坐标仍为原始图像 px，读取 JSON 时根据可选 `calibration` 换算实际距离，详见曲线格式；测量点和结果不写入保存文件，需根据真实节点及控制柄重新计算。


- **简化曲线点**：选中一条或多条曲线，在画布或曲线列表右键“简化曲线点…”，也可用“曲线与节点”面板同名按钮。默认允许偏差 0.01 mm，未标定默认 0.1 px；支持 mm/cm/px，未标定只提供 px。绿色叠加显示简化轮廓与新节点，显示各条及合计节点数；滚轮缩放、拖动画布平移，取消/Esc/预览中刷新不改作品。仅在减少节点且整条轮廓双向偏差核验通过时应用，保留端点、尖角、剪口、彩色节点、点位标注锚点、图层与样式；一步撤销/重做并自动记录。简化是显式容差内的近似，不保证零误差或数学全局最少；当前容差无法安全减少时保持原样。关联对称曲线需先解除关联，避免破坏两侧节点关系；隐藏/锁定曲线不可简化。

## 读取用户保存

“保存给 AI”在 **该项目、该工作区** 写入带时间戳的 JSON 和预览 SVG；实际保存目录以本次启动输出或 `/api/health.saves` 为准，每个目录有自己的 `latest.txt`。独立会话位于 `work/curve_editor/sessions/isolated/<会话ID的SHA-256>/`，命名共享位于 `sessions/shared/<共享名称的SHA-256>/`，仅 `--shared default` 使用旧的 `sessions/` 根目录。读取这份实际文件，报告保存时间、曲线与节点信息；需要核对形状时直接根据控制点渲染或展示相邻 SVG，不以 AI 重画代替核对。

读取时先确定当前会话或用户明确选择的共享工作区，再取该目录的 `latest.txt`，确认它是单个 `.json` 文件名，再读取同目录文件。没有保存文件时说明尚未保存，不从其他会话、共享组、旧版目录或别的项目找“最新”。保存只记录修改，不会自动发聊天或改写原图；将修改应用到用户目标文件时保留可追溯版本。

- 刷新与关闭页面：本机自动记录已完成时不再弹出浏览器的“可能不会保存更改”确认框，刷新后恢复画布与撤销/重做记录；尚未完成记录或本机记录不可用且有未保存修改时仍保留提醒。新建或打开其他作品前的覆盖确认保持不变。

- **两点尺寸标注**：先用两点标定设置实际比例，再点击左侧“尺寸标注”并点击两个位置，显示两点直线距离（mm/cm，保留两位小数）。默认放入“尺寸标注”图层；选中后拖两端圆点调整位置，拖方块调整尺寸线间距，属性区可改字号和单位。端点在创建或拖动时吸附可见节点并建立关联，原节点移动时尺寸线与数字实时更新；旧标注端点与某节点唯一重合时会在几何编辑中接续关联。插入节点保留原关联，删除关联节点或曲线后保留最后位置并解除该端关联。按 Alt 拖端点可解除关联；单独移动或变换整个标注会解除不在同一变换中的曲线关联，拖方块只调整间距。标注支持移动、等比缩放、旋转、撤销、保存及自动恢复；标定改变时重新计算。清除比例后显示“未标定”，恢复有效比例才能导出。AI/DXF/SVG 均带尺寸线、箭头与数字；AI/DXF 数字转轮廓，尺寸线为普通矢量线，不是 CAD 关联式 DIMENSION 实体。按所选图层导出时请一起选中标注所在图层。

### PLT 线稿导入

“打开修改”或拖入画布支持 `.plt`（HP-GL 折线），按 40 单位/mm 转为可编辑节点，保留抬笔分段、闭合轮廓及笔号图层，并自动标定实际尺寸。支持 IN、SP、PU/PD、PA/PR，接受 VS/PW/WU 机器参数；笔宽按编辑器默认线宽显示。当前不支持圆弧、文字、自定义缩放、旋转及虚线指令，遇到这些内容会明确拒绝，保留当前作品。PLT 仅导入，导出仍为 AI/DXF/SVG。

### 按实际尺寸追加线稿

顶部“导入线稿”或直接拖入 AI / DXF / PLT，会追加到当前画布的新图层；原作品名称、图片、文字、曲线和操作记录保留。导入内容放在当前视野中心，拖入时放在落点，并选中新曲线。已有标定时按文件与画布的实际比例换算节点和控制柄，不改原画布比例；提示导入件的毫米宽高。空白画布自动采用文件比例；有内容但未标定时先暂存文件，进入两点标定，填写原图中两点已知的实际长度并“应用比例”后自动继续导入。取消标定、切换作品或撤销会取消待导入内容。追加支持一步撤销/重做和本机恢复；“打开修改”仍是打开另一份作品。

### 扫描图片区域清理

推荐快捷流程：选中闭合曲线 → 右键“反选图片外区域” → 画布上红色高亮圈外 → 再次右键“删除所选图片区域”（或 Delete / Backspace）。第二次右键也可“反选图片区域”切换圈内/圈外；Esc、“取消图片区域选择”、普通点击或切换工具取消选区。反选只是临时预览，尚未删除；刷新不保留这个临时选区。

新提取的轮廓记住来源图片，曲线和图片无需同层；旧轮廓优先处理同层图片，没有同层图片时自动找范围内唯一的可编辑图片。存在多张重叠候选时，按 Shift 加选目标图片后使用；记住的来源图被删除、隐藏或锁定时明确提示，不误用其他图。圈外以目标图片边缘为界，适用于无限画布，无需毫米标定；不会删除图片之外的空白画布。顶部及右键“图片区域清理…”仍可打开详细预览。

删除处变透明；曲线、非目标图片、图片位置、旋转、实际尺寸及原始像素分辨率保留。多张目标图片暂存成功后一步提交，可撤销/重做，本机恢复与 JSON 保留结果；原扫描文件不覆盖。处理失败或中途取消不提交部分结果；超过 6400 万像素或单边 32767 像素的图片明确提示先分割，不降低分辨率。来源关联随保存恢复保留，复制时随同复制的图片重新关联；只复制曲线时不继承旧图关联。
