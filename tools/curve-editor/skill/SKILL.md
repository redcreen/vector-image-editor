# 通用矢量图编辑器

此 Skill 自带完整本机浏览器编辑器，无需复制其他项目或安装前端依赖。需要 Python 3.9+ 和浏览器，数据留在当前项目。

## 启动

以当前任务的实际项目目录作为 `--project`，不可把本 Skill 所在目录当成用户项目。解析符号链接后以实际目录隔离数据。

```sh
python3 /绝对路径/vector-editor/scripts/launch.py --project /绝对路径/当前项目
```

这里的 Skill 路径使用本文件所在目录，不要照抄占位路径。通过可保持运行的命令会话启动；程序前台运行，输出本次 URL 和保存位置。默认自动选择端口，只复用属于同一项目的服务。打开输出的真实 URL，不能默认使用其他项目已开的 8767 页面。可加 `--open` 打开系统默认浏览器，或用应用的浏览器工具展示 URL。工具仅监听 `127.0.0.1`，不创建登录启动项。

已有画布可能含未保存修改；导入另一份内容或刷新前，先通过“保存给 AI”保存当前作品。不要用示例覆盖用户作品。

## 生成、导入与修改

- PNG/JPG/WebP：用“导入底图”，或拖入、粘贴图片；底图锁定，只能在上面描线。
- 本工具 JSON：用“打开修改”，可直接编辑节点、控制柄和类型。生成可编辑线稿、转换已有节点或解释保存数据时，读取 [曲线格式](references/curve-format.md)。内置示例在 `assets/editor/examples/心形_可编辑示例.json`。
- SVG 仅支持导出；AI/CDR/PDF 不能直接导入。不要把位图说成可直接拖动节点的矢量图。
- 保持图形比例和节点类型；这是图像像素坐标，未经另行标定不能声称是毫米尺寸或生产切割稿。

## 镜像与测量

- “对称轴”（A）：点击两点画任意方向的轴，靠近节点吸附，Shift 约束角度。选曲线后点击“生成镜像副本”，或使用曲线右键同名操作；保留原曲线，副本的节点和控制柄仍可编辑。对称轴随 JSON 保存，不导出到 SVG。
- “测量”（M）→“点距测量”：连续点选位置，显示各段直线距离及累计值；Enter / Esc 结束，下一次点击开始新测量，Backspace 回退一个点。
- 右键“测量整条曲线”显示实际贝塞尔弧长。部分曲线用“选段测量”：点击首段，再 Shift 点击末段，包含首尾及中间连续线段；闭合曲线可切换另一侧。也可右键“从这段开始测量”及“测到这一段（连续选段）”。
- 距离单位为原图 px，曲线弧长是数值近似；缩放不改变距离。测量点和结果不写入保存文件，读取 JSON 后需要测量时应根据真实节点及控制柄重新计算。

## 读取用户保存

“保存给 AI”在 **该项目** 的 `work/curve_editor/sessions/` 写入带时间戳的 JSON 和预览 SVG；`latest.txt` 指向最新 JSON。读取这份实际文件，报告保存时间、曲线与节点信息；需要核对形状时直接根据控制点渲染或展示相邻 SVG，不以 AI 重画代替核对。

读取时先取 `latest.txt`，确认它是单个 `.json` 文件名，再读取同目录文件。没有保存文件时说明尚未保存，不从别的项目找“最新”。保存只记录修改，不会自动发聊天或改写原图；将修改应用到用户目标文件时保留可追溯版本。
