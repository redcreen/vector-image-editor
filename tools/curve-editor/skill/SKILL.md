# 通用矢量图编辑器

此 Skill 自带完整本机浏览器编辑器，无需复制其他项目或安装前端依赖。需要 Python 3.9+ 和浏览器，数据留在当前项目。

## 启动

以当前任务的实际项目目录作为 `--project`，不可把本 Skill 所在目录当成用户项目。解析符号链接后以实际目录隔离数据。

```sh
python3 /绝对路径/vector-editor/scripts/launch.py --project /绝对路径/当前项目
```

这里的 Skill 路径使用本文件所在目录，不要照抄占位路径。通过可保持运行的命令会话启动；程序前台运行，输出本次 URL 和保存位置。默认自动选择端口，只复用属于同一项目的服务。打开输出的真实 URL，不能默认使用其他项目已开的 8767 页面。可加 `--open` 打开系统默认浏览器，或用应用的浏览器工具展示 URL。工具仅监听 `127.0.0.1`，不创建登录启动项。

已有画布可能含未保存修改；打开另一份作品或刷新前，先通过“保存给 AI”保存当前作品。不要用示例覆盖用户作品。工具更新后先保存旧页面，再重新启动；旧服务缺少新版能力时会另开端口，保留旧页面。

## 生成、导入与修改

- PNG/JPG/WebP：用“导入图片”，或拖入、粘贴图片；在当前画板新增图片图层，不替换已有作品或清除标定。图层可命名、隐藏、锁定、排序和删除；旧底图转为锁定图层，可解锁。图片仍是位图，不能拖节点改轮廓。
- “提取线条”（T）：在图片上悬停，按颜色容差、连接距离和平滑程度跟踪局部线条；实线或虚线均以蓝色预览，点击后生成节点与控制柄仍可编辑的曲线。来源图片保留，处理只在本机进行，不调用大模型。颜色混杂、遮挡或边界不清的区域可能提前停止，应分段提取或手工补线；虚线只是连续几何的显示样式。此功能辅助描线，不应描述为可全自动提取任意照片。
- 选取工具可移动图片或曲线、拖角等比缩放，也可在“位置与尺寸”输入像素位置和宽高。空白处框选，Shift 点击多选；全选排除隐藏和锁定图层。新曲线画在当前图层，同层图片位于曲线下面。图层和图片变换随 JSON 保存，支持撤销重做。
- 节点工具框选节点后，右键“顺滑所选节点”按相邻节点走向重新计算控制柄，让连线转折更圆润；在所选节点、连线或空白处右键均可操作。保持节点位置、数量和未选节点，支持跨曲线多选及闭合曲线，一步撤销/重做，不改变新节点默认类型。共线节点仍保持直线；重合点和原路折返处不强行制造弧度。
- 曲线列表按住 Shift 点击多选，再右键所选项“合并曲线”。仅合并至少含两个节点的开放曲线，按最近端点连接，反向时交换控制柄；重合端点合为一个节点，空隙用直线连接，原有曲线段形状不变。沿用最后选中曲线的名称、线色、用途、虚线样式、说明及图层，继续编辑节点或一步撤销/重做；闭合曲线先打开，隐藏/锁定曲线不参与。
- 曲线列表或画板上的曲线右键可“删除曲线”；Shift 多选后在所选曲线上右键“删除所选曲线”，一步撤销/重做并恢复图层归属及选择。右键未选中曲线则仅操作该曲线；隐藏/锁定曲线不参与，节点的“删除这个节点/删除所选节点”仍是独立操作。
- 选中曲线，在画板或曲线列表右键“偏移曲线…”：闭合轮廓按 mm/cm 外扩或内收，开放曲线按起点到终点向左/右偏移，蓝色箭头标方向、绿色预览新曲线。须先两点标定；未标定时窗口提供入口。所选开放曲线端点间距严格小于 0.01 px 自动拼合成链或闭合轮廓，不跨空隙补线；多个独立轮廓分别处理。生成新的可编辑曲线并保留原作，继承来源样式和图层，一步撤销/重做；取消、Esc、刷新不保存预览。自交、分叉、过大内收导致消失及结果超限时提示调整，不生成部分结果。极尖角截短尖刺，曲线数值近似后拟合为贝塞尔节点；本机附带 Clipper 算法及许可，不依赖联网。
- 本工具 JSON：用“打开修改”，可直接编辑节点、控制柄和类型。生成可编辑线稿、转换已有节点或解释保存数据时，读取 [曲线格式](references/curve-format.md)。内置示例在 `assets/editor/examples/心形_可编辑示例.json`。
- “操作记录”支持最近 100 步的逐步预览、自动重放、暂停和速度调整；停止、Esc 或播放结束回到原作品，不改撤销/重做位置。本机浏览器按项目身份保存当前画布、图片和记录，同一浏览器地址刷新可恢复；面板显示保存状态，存储不可用时提示。“另存为…”（Cmd/Ctrl+Shift+S）保存独立 JSON 副本，包含最近 100 步、撤销/重做位置、选择和历史图片；在编辑器内的对话框输入文件名，确认“保存副本”后下载到浏览器的下载位置，可在下载列表查看。用“打开修改”重开副本可继续撤销、重做和重放；记录图片去重，另存为使用紧凑 JSON，含记录文件及“打开修改”的上限均为 256MB。“保存给 AI”（Cmd/Ctrl+S）仅保存当前作品，不含操作记录或历史图片，以减少 AI 读取量；另存为不更新项目 latest.txt。升级前先保存旧页面，旧版本未记录的操作无法补回。
- SVG 仅支持导出；AI/CDR/PDF 不能直接导入。不要把位图说成可直接拖动节点的矢量图。
- 保持图形比例和节点类型；这是图像像素坐标，未经另行标定不能声称是毫米尺寸或生产切割稿。

## 镜像与测量

- “对称轴”（A）：点击两点画任意方向的轴，第二点接近水平或竖直 5° 内自动吸附，轴旁显示方向，移开恢复自由方向；靠近节点吸附，接近水平或竖直时优先矫正轴方向，Shift 约束角度。选曲线后点击“生成镜像副本”，或使用曲线右键同名操作；保留原曲线，副本的节点和控制柄仍可编辑。对称轴随 JSON 保存，不导出到 SVG。
- “测量”（M）→“点距测量”：连续点选位置，显示各段直线距离及累计值；Enter / Esc 结束，下一次点击开始新测量，Backspace 回退一个点。
- 右键“测量整条曲线”显示实际贝塞尔弧长。部分曲线用“选段测量”：点击首段，再 Shift 点击末段，包含首尾及中间连续线段；闭合曲线可切换另一侧。也可右键“从这段开始测量”及“测到这一段（连续选段）”。
- 实际长度：点“两点标定”，在图中点击两个已知距离的位置，填写实际长度并选择 mm/cm，点“应用比例”。所有测量随后按该比例换算，显示单位可在 mm/cm 间切换。标定比例与显示单位随 JSON 保存；新建画板后需重新标定；导入图片保留已有比例，图片是否与画板同一比例需要已知距离核对。没有已知距离时保留 px，不从图片猜测实际尺寸。
- 曲线弧长是数值近似，缩放不改变距离。坐标仍为原始图像 px，读取 JSON 时根据可选 `calibration` 换算实际距离，详见曲线格式；测量点和结果不写入保存文件，需根据真实节点及控制柄重新计算。

## 读取用户保存

“保存给 AI”在 **该项目** 的 `work/curve_editor/sessions/` 写入带时间戳的 JSON 和预览 SVG；`latest.txt` 指向最新 JSON。读取这份实际文件，报告保存时间、曲线与节点信息；需要核对形状时直接根据控制点渲染或展示相邻 SVG，不以 AI 重画代替核对。

读取时先取 `latest.txt`，确认它是单个 `.json` 文件名，再读取同目录文件。没有保存文件时说明尚未保存，不从别的项目找“最新”。保存只记录修改，不会自动发聊天或改写原图；将修改应用到用户目标文件时保留可追溯版本。
