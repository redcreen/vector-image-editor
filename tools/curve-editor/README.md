# 通用矢量图编辑器

项目内可复用的本机矢量曲线编辑工具，操作参考 CorelDRAW 的贝塞尔和节点工具。图片及修改保留在本机，无需联网或安装前端依赖。AI 的 PDF 容器解析使用随工具附带的 pypdf 及许可。

页面顶部、浏览器标签和状态栏列表均显示“正式版”或“测试版”。日常启动为正式版；自动验证设置 `CURVE_EDITOR_EDITION=test`，使用独立列表、`work/curve_editor/test-sessions` 保存目录和系统临时端口（`--port 0`），不会接入正式版页面或复用正式版服务。直接打开 HTML 显示测试版；日常编辑请使用启动器打开本机 HTTP 页面。

当前源码维护项目为 `/Users/redcreen/Project/imgEditor`，2026-10-09 从 daban 迁入。后续修改在本项目完成，验证通过后自动用安装脚本发布到共用 Skill，并核对同步结果；状态栏源码变更时同步重建已安装应用，无需再次确认。

## 启动

在项目根目录双击 **打开通用矢量图编辑器.command**，浏览器会打开本项目对应的本机地址。默认从 8767 自动选择空闲端口，以启动输出为准。旧“打开改线台.command”仍可使用。

画布默认在系统浏览器中通过完整 `http://127.0.0.1:<端口>` 地址打开，启动带 `--open`；用户指定其他浏览器时遵照其选择。状态栏只提供管理入口，打开和新建画布均访问浏览器中的本机网页。

需要 Python 3.9+ 和现代浏览器。关闭提供服务的终端窗口后，如页面无法使用，重新双击启动入口。

## macOS 状态栏

底部“重新启动”位于“退出”左侧，用于重启编辑服务或恢复意外停止的服务。保持原访问地址、作品工作区和保存目录，保留浏览器画布及本机操作记录，不自动刷新页面。已移除的作品不会恢复；端口冲突等失败会明确提示，可以处理后重试。

点击名称或打开图标时，优先切换已运行的 Chrome、Safari、Edge、Brave 中相同完整地址的标签页，没有匹配才交给默认浏览器新开。根地址末尾有无斜杠等价，端口、主机及 client 参数保持区分。首次使用可能需要 macOS 自动化授权；检查失败时提示原因，不把无法检查误判为没有页面。

双击根目录 **打开编辑器状态栏.command**，或打开 `~/Applications/通用矢量图编辑器.app`。首次构建需要 macOS 命令行开发工具；状态栏使用图片加铅笔图标，不创建开机启动项。

- 点击图标查看本机正在运行的编辑器；点击名称打开完整页面地址。新服务启动时自动登记，默认名称优先使用对应 Codex 聊天标题，找不到标题时使用项目/会话标识。
- 每行铅笔可改名，垃圾桶可关闭并移除。名称同时显示在网页顶部和标签页；网页顶部的铅笔也可以命名。改名保留画布、撤销记录和原保存目录。
- **新建页面…** 输入「通用矢量图编辑器 ·」后的名称，选择项目目录；每次创建独立空白工作区，不覆盖已有页面。新建的服务不依赖终端窗口存活。
- 关闭服务保留已保存作品，打开的网页标签不会强制关闭。有未保存页面时提示先保存；关闭时的状态消息有序号保护，避免旧消息误报。浏览器崩溃等未正常退出的情况会保守保留未保存状态，应先恢复并保存浏览器草稿，再重新启动对应服务，不按超时猜测稿件已安全。
- 旧版服务没有安全关闭接口时，只能从菜单隐藏；改名只更新该旧版菜单条目。共享服务仍有其他菜单成员时，只移除本成员，保留其他成员的服务。
- **退出** 仅退出状态栏，编辑器服务继续运行。再次打开应用可重新查看列表。

名单及管理凭据留在 `~/Library/Application Support/CurveEditor/editors/`，名称留在各工作区 `.editor.json`。应用使用共用 Skill 的管理程序；维护源码后先验证，再运行安装脚本同步。

## 操作

- **同地址页面接续**：同一浏览器打开相同完整地址的 A/B 两页，A 编辑后等待“已保存在本机 · 刷新可恢复”，B 刷新即可接续最新画布、图片和操作记录（含撤销/重做位置），无需点“保存给 AI”。旧页只刷新、关闭或调整视图不会覆盖另一页的新作品；当前打开的画布不实时替换。不同改动形成的分支和升级期间发现的旧版记录保留在本机。首次升级先刷新内容正确的页面，再刷新其他相同地址页面，全部载入新版后继续编辑。仅名称相同不代表同一个工作区。
- **左侧工具栏**：从页面顶部贯穿到窗口底部，右侧排列文件操作、画布和属性面板。工具使用紧凑图标及文字，不需要滚动。拖动左栏右边缘调整宽度，宽度达到 132 px 自动排为两列，收窄恢复单列；窗口较矮时自动提供双列空间。双击边缘或聚焦后按 Home 恢复默认，← / → 调整宽度，Esc 取消拖动。宽度、折叠状态自动记住，保留当前作品、缩放和画布中心，不占撤销记录。
- **侧栏与分组**：左右侧栏顶部的双箭头可独立收起/展开。左侧收起后保留工具图标及快捷键；右侧收起后保留功能图标，点击可展开并定位对应组。右侧按图层、对象属性（位置尺寸与曲线属性）、曲线与节点、镜像、测量、图片与视图分组，帮助单独收起；点击组标题可独立折叠，拖动标题上下换序，Alt + ↑ / ↓ 可用键盘换序，收起后的图标入口沿用新顺序。首次打开仅展开图层，切换绘图工具会展开相关组；主动收起右栏时仍保持收起。拖动右栏左边缘调整宽度，拖动已展开功能组底部的横条调整内容高度；内容过长可在组内滚动，拉高图层等列表区域可显示更多条目。双击拖拽条或选中后按 Home 恢复默认，方向键每次调整 10 px（Shift 为 50 px），Esc 取消正在进行的拖拽。窄屏仅调整组高度。浏览器记住侧栏、分组折叠、排列顺序、尺寸和侧栏/组内滚动位置，刷新后恢复，不写入作品或撤销历史。收起侧栏或调整窗口大小时保留当前缩放和视图中心。
- **打印选中曲线**：选一条曲线或 Shift 多选，点击顶部“打印选中曲线…”、曲线右键同名项，或按 ⌘ / Ctrl + P。必须先完成两点标定；按 mm/cm 比例计算真实贝塞尔边界并显示毫米宽高，与画布缩放无关。支持 A4/A3 横竖方向，超页自动分片、相邻页重叠 5 mm，最多 100 页；保留曲线相对位置，仅输出黑色曲线线稿和虚线样式，不含底图、文字、节点或辅助线。打印窗口选相同纸张和方向，缩放设为 100% / 实际大小，关闭适合纸张及页眉页脚；纸上附 50 mm 校验线。打印与取消均不修改作品、标定或撤销重做记录。
- **导入图片**：画板上方操作区、图层右键或画板右键均可导入 PNG、JPG、WebP；也可拖入图片，或从截图/其他应用复制图片，点击画布后按 ⌘ / Ctrl + V 粘贴。每次导入在当前画板新增独立图片图层，保留已有曲线、画板尺寸、标定和历史，不再重建画板。图片以自身像素尺寸放入视图中央，拖入时放在落点附近；粘贴后自动选中图片，可移动、缩放及一步撤销/重做。输入框内继续按原样粘贴文字。
- **提取线条 · T**：在图片上移动鼠标，工具会按设置的颜色容差、连接距离和平滑程度寻找局部线条；实线或虚线均以蓝色预览，点击后生成节点和控制柄仍可编辑的曲线。提取保留来源图片，全部在本机处理，不调用大模型；颜色混杂、遮挡或边界不清的区域可能提前停止，需要分段点击或手工补线。虚线只是连续曲线几何的显示样式，节点仍沿同一条路径排列。本功能用于辅助描线，不保证任意照片都能全自动提取。
- **提取外轮廓 · Shift + T**：指向物体内部或外边缘预览完整外框，点击（或 Enter）生成一条闭合、可编辑的曲线；Esc 取消。针对背景简单、物体与背景分界清楚的实物照片及透明图片，保留外缘凹口，忽略内部纹理与孔洞；多个分离物体按鼠标位置分别提取。右侧独立调节背景容差、去毛边和拟合误差。增大背景容差可排除浅色阴影；去毛边（默认 8 px，0 关闭）先滤除细小突出和缺口，再沿主体走势平滑、拟合为贝塞尔曲线。拟合误差（默认 2 px）相对去毛边后的轮廓计算，越小越贴合，越大节点越少；整段曲线校验偏差，避免控制柄外鼓。去毛边和拟合误差均按原图像素计算，只影响重新提取的曲线；过强去毛边也会抹去真实细节、断开细颈，需对照预览；断开时选择鼠标所在部分。图片保留，支持撤销、重做及保存；处理均在本机，照片边缘应留有足够背景；背景复杂或边界模糊时需人工修整。
- **贝塞尔**：点击加直线节点，按住拖动拉出曲线手柄；点回起点闭合，Enter / Esc 结束。
- **矩形 · R / 椭圆 · E**：选中可编辑普通图层后，在画布任意方向拖动绘制，松开生成闭合曲线，可连续绘制；按 F10 继续编辑节点。拖动时显示宽高，宽高相差不超过长边 5% 时绿色提示接近正方形或圆形；普通拖动不强制吸附，按住 Shift 约束等宽高，松开恢复自由比例。已标定显示 mm/cm，否则显示 px。Esc、切换工具、失去焦点或指针取消时丢弃预览，不留下空曲线或撤销记录；点击及不足 2 屏幕像素的窄形状不生成。每个形状可一步撤销/重做，归属当前图层，支持 JSON 恢复和 AI/DXF/SVG 导出。椭圆/圆使用四段三次贝塞尔近似（标准 kappa，归一化半径最大误差约 0.0273%），保存为普通可编辑节点；DXF 的 0.01 mm 近似误差相对于这条贝塞尔曲线计算。
- **文字 · F8**：选择文字工具后在画布点击放置文字；可输入多行内容，并在属性区调整内容和字号。新文字默认进入“文字图层”，不存在时在确认创建文字后自动新建，取消不留下空层；已有文字编辑时保留所属图层。文字随图层隐藏、锁定、排序、删除和保存；画板外文字也会纳入 SVG 导出范围。
- **点位标注**：点左侧“点位标注”，再点曲线或节点；也可右键目标位置选“添加点位标注…”。输入 1–32 位英文字母或数字（如 `01`、`A1`），保留前导零，自动生成圆点、短引线和文字。默认复用“位置标注”图层，不存在时在确认后创建；取消不留空层，隐藏或锁定时提示解锁。双击修改内容和字号，也可在对象属性修改；支持移动、等比缩放、旋转、删除、撤销重做及自动保存恢复。标注模式持续显示可见曲线的节点，创建后可连续点击下一个位置；Esc 回到节点工具，V 切换选取。标注关联创建时的曲线，随整条曲线移动、缩放和旋转，旋转时文字保持水平正向；同时选中曲线和标注也只变换一次。标注记住对应节点或曲线段落点：单独拖动节点、调整控制柄和改变曲线形状时实时跟随，文字与点位的间距保持且文字水平正向。增删节点后在所属曲线内重定位，断开曲线时关联分配到对应片段；撤销、重做与本机恢复保留关联。SVG 保留标注，AI/DXF 将文字、圆点和引线转为轮廓线，打印选中曲线不含标注。
- **更换所属图层**：在图层列表中拖动文字、曲线或图片到目标普通图层名称（折叠时也可接收），或拖到目标图层已展开的内容区域；已选元素支持一起移动，未选元素拖动时仅移动自身，成功后展开目标图层。同层曲线仍可拖动上下排序，Esc 或放到画布空白处取消。也可选中文字、曲线或图片后，在“对象属性 → 所属图层”选择目标普通图层，可一次移动跨图层的多种元素。保留内容、坐标、节点和控制柄，移入目标已有内容上方，支持一步撤销/重做、保存和刷新恢复；隐藏、锁定图层及其子层不能作为目标，图层组须选择其中的普通图层。
- **节点 / 选取**：双击曲线插点；节点工具拖方点改位置、拖圆柄改弧度；选取工具拖动整条曲线。
- **线段切换 · J**：节点工具点击两个节点之间的线，蓝色高亮这一段；按 J 在直线段和曲线段间切换，或点击“收起手柄 · 直线段”仅转为直线。只改变起点的出手柄与终点的入手柄，相邻线段保持不变；节点两侧独立，所以可以一侧直线、一侧曲线。曲线段显示两端对应的手柄，拖动仍只调整本段。直线转曲线生成可编辑手柄，共线时外观可能保持直线，可拖动调整弧度。闭合曲线的末段同样支持，整次切换可一步撤销/重做；选择可随本机记录及含历史的副本恢复。点击节点回到节点编辑，J 继续切换整个所选节点。
- **右键**：选中开放曲线的单个端点，右键“继续画线”从该端点续画，首端和末端均支持；点击加点、拖动拉出手柄，点回另一端可闭合，Enter / Esc 结束。保留原线段、控制柄、样式和图层，新增节点可撤销/重做，刷新后保留续画方向。曲线上插点，内部节点可断开、删除或切换类型，空白处可续接或新画一条。曲线列表或画板上的曲线右键可“删除曲线”；Shift 多选后右键“删除所选曲线”，整组删除可一步撤销/重做，恢复曲线、图层归属及多选状态。右键未选中的曲线只操作该曲线，隐藏/锁定曲线不参与。
- **曲线列表**：每行眼睛可单独显示／隐藏曲线，隐藏后保留列表条目，便于重新显示；隐藏曲线不参与选择、编辑、测量及 SVG 导出，不影响同层其他曲线。双击曲线名称在列表内重命名，失焦或 Enter 确认，Esc 取消，空名称保留原名；中文输入法选字时 Enter 不提前确认。拖动曲线条目上下换序，蓝线提示插入位置，保留多选、图层归属和节点坐标；可见性、命名与排序均支持撤销重做、保存及刷新恢复。隐藏图层仍可展开查看内容，但元素不可编辑；重新显示图层时保留各曲线自己的可见性；锁定图层的曲线仍列出但不可编辑或切换可见性。
- **断开连接与端点重接**：节点工具选中闭合曲线任意节点，或开放曲线内部节点，点顶部或右键“断开连接”。闭合曲线在该点展开为一条开放曲线，开放曲线分成两条；断口两端起初重合，原有贝塞尔线段形状保留，直接拖动当前端点即可分开。单个开放端点拖到另一可编辑开放端点的 3 个屏幕像素内，绿色提示松开选择连接或仅重合；拖到自身另一端可选择闭合（闭合后至少三个节点）。松开后在旁边选择“连接节点”或“仅保持重合”，默认聚焦仅重合；Esc、点击别处或切换窗口同样保持两个独立端点，坐标精确重合，之后可分别拖开。只有确认连接才合并为一个节点；跨曲线连接沿用拖动曲线的样式、名称和图层。也可按 V 使用选取工具，单选后拖动整条开放曲线；节点工具从曲线列表单选后拖动，或只选中该曲线的全部节点拖动，同样支持连接。所有节点与控制柄保持整体平移，多对端点接近时只提示距离最近的一对，松开后只询问这一对，确认连接后保留整条曲线选择。连接端点优先于普通节点对准。Alt 取消吸附连接；部分节点、多条曲线、图片/文字混选或控制柄拖动不连接，隐藏和锁定内容不参与连接。断开、拖动后选择连接或仅重合均可一步撤销/重做；菜单打开时也自动记录移动，未作选择就刷新将恢复为独立重合端点及原有撤销记录。保存及刷新恢复保留结果。
- **重合的端点改为连接**：框选或多选至少两条可编辑曲线后，在画布、节点或曲线列表右键使用。按所选完整曲线处理，只连接坐标完全相同的开放端点，保留原弧线和控制柄，不跨空隙补线；多个独立轮廓分别连接，首尾相接且至少三个节点时自动闭合。同一点有三个以上端点时跳过该分叉并提示。隐藏/锁定曲线不参与；每组优先沿用当前主选曲线的样式和图层；主选曲线不在该组时沿用该组第一条。节点位置标记及尺寸标注关联跟随迁移，整次操作可一步撤销/重做及保存恢复。
- **合并曲线**：在曲线列表按住 Shift 点击多选，再右键所选项 →“合并曲线”。按最近端点连接开放曲线，必要时自动反转节点顺序及控制柄；重合端点合为一个节点，端点间的空隙用直线连接。原有曲线段形状保持不变，合并后继续编辑节点，可一步撤销/重做。沿用最后选中曲线的名称、颜色、用途、虚线样式、说明及所在图层；闭合曲线须先打开，隐藏/锁定曲线不参与。
- **偏移曲线**：选中一条或多条曲线，在画板或曲线列表右键 →“偏移曲线…”。方向由距离的正负控制：闭合轮廓正数外扩、负数内收；开放曲线正数向左侧、负数向右侧，左右按起点到终点的方向判断，蓝色箭头辅助确认。输入非零距离及 mm/cm（例如 +5 mm 外扩、-5 mm 内收），绿色实时预览，点击“生成新曲线”后保留原曲线，并选中新生成的可编辑曲线；取消、Esc 或预览期间刷新不改变作品和历史。先用现有“两点标定”设置实际比例，未标定时窗口提供标定入口。
- **多段轮廓偏移**：所选开放曲线的端点距离严格小于 0.01 px 时自动拼合，必要时反向；共同围成封闭轮廓后整体外扩/内收。存在空隙时保持开放，需先编辑端点或通过“合并曲线”补线，再闭合；交汇端点存在分叉时提示重新选择。多个独立轮廓分别处理，混合选择闭合和开放曲线时使用同一正负距离，正数外扩/左偏、负数内收/右偏。每个新轮廓继承来源曲线的颜色、用途、虚线样式、说明和图层；拼合轮廓优先继承最后选中的来源，否则继承所选来源中的第一条。整次生成算一步撤销/重做，保存/重开继续编辑节点和控制柄。
- **偏移边界**：平滑部分采用数值近似并拟合为贝塞尔曲线，闭合曲线优先沿用原节点数量拟合，独立核对整条轮廓的双向偏差，精度不足时才增加节点；预览显示前后节点数，不保证任意形状均能保持原节点数量。可选择自动精度或 0.01 / 0.02 / 0.05 / 0.1 mm 允许偏差，点击“比较不同精度”查看各档节点数，可逐档勾选“一起预览”叠加彩色轮廓，或全选叠加；“设为主方案”切换绿色主预览，只生成主方案，比较和取消不修改作品。所有候选结果均核对双向距离，未通过时收紧拟合或明确提示，生成曲线的说明保留所选允许偏差。尖角使用有限尖角连接，极尖转折截短尖刺。简单凹形支持清理和分裂为多个新闭合轮廓。原轮廓自交、开放曲线偏移后自交/折返、内收过大消失或结果超过坐标/节点/曲线数量限制时提示调整，整次不生成部分结果。每次偏移后的节点合计不超过 10000，作品曲线不超过 500 条。图中缩放不改变偏移距离。
- **调整**：尖角、平滑、对称。选择会应用于当前节点，也作为之后新点的默认类型；可在尚未画点时选择。各旧节点保持各自类型，默认类型随修改文件一起保存。选中节点后按 J，在直线节点与平滑节点之间切换：所选均为直线节点时转为平滑，否则统一收起手柄转为直线；支持多选和一步撤销/重做，不改变新节点默认类型。输入文字时不触发。Alt 拖手柄仅调整一侧；方向键微调节点。
- **顺滑**：节点工具框选一部分节点后，右键 →“顺滑所选节点”。在所选节点、连线或空白处右键均可使用；按照相邻节点的走向重新计算控制柄，让转折更圆润。节点位置、数量和未选节点保持不变，支持跨曲线多选及闭合曲线，整次操作可一步撤销/重做；不改变新节点的默认类型。共线节点保持直线，重合点或原路折返处不强行生成弧度。
- **整段圆顺**：节点工具（F10）选中同一条曲线上连续的 3–200 个节点，右键“整段圆顺…”或在节点面板点击同名按钮。首尾点固定，中间点默认作为允许微调的参考点；窗口中勾选“必须经过”可固定指定中间点。允许偏离限制相对原贝塞尔曲线的整段距离（不是只检查节点），已标定可用 mm/cm/px，未标定仅用原图像素 px。原线作对照、绿色预览、金色固定点与空心绿色参考点均带原节点编号；预览期间可滚轮缩放、直接拖动画布平移，也可使用顶部缩放与适合窗口；节点和其他编辑操作暂时停用。计算不写入作品，取消/Esc/预览中刷新不改图。应用只修改所选跨度，保留点数、顺序、首尾位置、端点原有切线方向及外侧手柄，其他线段保持不变；一步撤销/重做并随自动记录恢复。支持闭合曲线跨末段的局部选择，不支持整圈或跨多条/不连续选择。内部通过联合三次样条计算连接处连续的切线和曲率；候选搜索及误差验证较保守，限制过小或点位约束不相容时会提示增大偏差/调整必经点，不自动放宽。保留原有首尾尖角，不保证改变所选段之外的接头曲率，也不自动消除跨段自交。
- **视图**：滚轮缩放，按住 Ctrl 或空格临时平移，“适合窗口”恢复完整画板。所有画布工具都支持临时平移；节点、控制柄、整条曲线、缩放和旋转拖动中也可按住 Ctrl 移动画布，松开后继续原操作，保留选段、多选和未完成曲线，平移不占撤销历史。输入框内保留原有快捷键。
- **无限画布**：背景和网格随平移、缩放向四周延伸，可在原底图外和负坐标区域继续画线。底图尺寸和原图像素坐标保持不变；“适合窗口”包含越界曲线，导出 SVG 和保存叠图会自动扩大范围，避免裁掉画板外的作品。
- **框选与全选**：选取工具（V）从空白处拖出矩形，选中框内或穿过框的曲线；节点工具（F10）框选节点：先选中一条曲线，随后框选只选该曲线节点，重叠副本保持可见也不会混入。未选曲线或已选多条时仍可跨曲线框选；Esc 清空后可重新跨曲线选择。Shift 点选增加或取消，Shift 框选追加；工具栏“全选”或 Cmd/Ctrl+A 全选当前工具对应的曲线或节点，Esc /“取消选择”清空。框选后直接在选区内部拖动，或拖动已选曲线、节点整体移动，方向键微调、Shift 方向键移动 10 px；Delete 批量删除。多条曲线可一起改色、改用途、闭合或镜像；多节点可一起改类型或收起手柄。一次批量修改算一步撤销，撤销也恢复选中状态。名称、备注仍逐条编辑；输入框里的全选保留文字编辑行为。
- **节点对准**：拖动节点或整条曲线时，距离其他可见节点不超过 3 个屏幕像素才自动吸附，并显示绿色圆环与“节点重合”。放大后实际吸附范围随之缩小；按住 Alt 临时自由移动，松开恢复，Shift 方向约束优先。支持同一曲线未移动的节点和可见锁定参考，排除隐藏内容及一起移动的节点；整组共用一个位移，保留形状和控制柄，一次拖动仍为一步撤销。提示只在拖动期间显示，不写入作品或导出。
- **选中线段复制**：节点工具（F10）点击两节点之间的线，蓝色高亮后按 Cmd/Ctrl+C，或点工具栏“复制”／右键“复制线段”；按 Cmd/Ctrl+V 粘贴到当前可编辑图层，也可先选目标图层。副本是只有该段两个端点的开放曲线，相同比例下保持原坐标、弧度、用途、虚线和备注，并自动换成不同颜色，仅保留本段使用的控制柄；可独立移动、修改，粘贴后自动选中，可直接拖走。原曲线不变，一步撤销/重做；闭合曲线的末段同样支持。在曲线列表选中曲线后复制，仍复制完整曲线。
- **元素复制粘贴**：选中曲线、图片、文字、点位或尺寸标注后按 Cmd/Ctrl+C（或工具栏“复制”），点击目标图层，把鼠标移到画布落点，按 Cmd/Ctrl+V。整组选中元素的轴对齐包围框左上角对齐鼠标，旋转图片和文字按旋转后的范围计算，元素间相对位置与叠放顺序保留。工具栏“粘贴”和右键“粘贴元素”沿用鼠标最后停留的画布位置；尚未进入画布时用视野中央。曲线保留节点、控制柄、闭合、虚线与备注，副本换线色；图片保留内容、透明度和旋转，文字保留内容、字号和旋转。同批复制的标注关联到新曲线，单独复制标注不会继续绑定原曲线。支持一步撤销/重做及本机恢复；目标必须是显示且未锁定的普通图层。选中的页面名称、ID 和输入框文字仍按普通文字复制。跨页面、端口和项目粘贴使用同一本机、同一正式/测试类别最近主动复制的元素，无需读取系统剪贴板权限。复制时携带实际比例，粘贴时按目标标定换算曲线、图片、字号与标注，保持物理大小；空白目标采用来源比例，已有内容但未标定的目标先标定，再粘贴到原先图层和落点；未标定来源只允许本页按像素粘贴，跨页必须先标定。复制后等待“可跨页面粘贴”；旧页面请刷新后重新复制。其他应用的图片用 Cmd/Ctrl+V，图片左上角同样对齐鼠标，并放入新图片图层。
- **历史**：工具栏的左弯箭头撤销、右弯箭头重做，可以连续点击逐步回退或恢复，最多保留 100 步；悬停显示可用步数，没有可用操作时按钮变灰。Cmd/Ctrl+Z 撤销，Cmd/Ctrl+Shift+Z 或 Ctrl+Y 重做。节点、控制柄或整条曲线的一次拖动算一步，名称、备注、颜色和图片透明度的一次连续调整算一步；单纯选择和视图缩放不占历史。撤销后有新的修改会清空后面的重做记录。
- **操作记录与重放**：点击工具栏“操作记录”或右侧同名面板，查看最近 100 步的操作名称及当前位置。点击某一步预览，或用上一步/下一步查看；“重放”从起始状态自动播放，支持暂停、继续和三档速度。“回到当前作品”、Esc 或播放结束返回原作品及原撤销/重做位置；预览期间暂时停止编辑，刷新也恢复真实作品。撤销后的记录标为“已撤销”，产生新修改后移除。
- **刷新恢复**：当前画布（含尚未点击“保存给 AI”的修改）、图片和操作记录按项目身份自动存入本机浏览器 IndexedDB，图片内容在记录中去重。刷新前还会同步备份最后一次输入或拖动，备份引用已保存的图片，避免大图重复占用空间。面板显示“已保存在本机”后，同一浏览器、同一编辑器地址刷新可恢复并继续重放；恢复期间再次刷新不会覆盖草稿。浏览器草稿不会上传；“另存为”可将记录带入作品 JSON。“保存给 AI”不附带记录。浏览器数据清理、换浏览器或更换端口不会自动迁移草稿；存储不可用或空间不足时有提示，仍可编辑、重放和手动保存作品。

## 图层与元素

- 右键图层选择 **置顶**，一次移到当前最上层；之后仍可拖动排序，新建图层也可位于其上方。已在最上层时禁用该项。置顶保留可见性、锁定状态和图层内容，支持一步撤销/重做与保存恢复。
- 右侧 **图层** 面板按从前到后的顺序显示。右上角小加号新建图层；加号左边的眼睛按钮可显示或隐藏全部图层（含锁定图层），部分可见时点击显示全部，操作支持一步撤销/重做；眼睛前的复选框全选图层，取消勾选清空选择，部分选中时显示半选状态；隐藏、锁定图层和折叠组的子层也参与图层选择，画布只编辑可见且未锁定的内容；拖动图层名称调整顺序，蓝线提示插入位置。每行的垃圾桶删除该图层，双击图层名称可重命名，右键图层也可重命名、删除、新建或导入图片；重命名在列表内输入，Enter 或失焦确认，Esc 取消，空名称保留原名。每行眼睛按钮切换该图层可见性；开锁/闭锁图标表示未锁定/已锁定，点击可切换。鼠标悬停显示操作提示。排序、命名及删除均支持撤销重做。删除图层会一起删除其中元素，可撤销。旧作品的曲线归入“曲线图层”，旧底图转换为锁定的“底图”层。
- 文字内容、曲线和图片统一列在所属图层下，默认折叠；点击图层左侧箭头展开，再点击元素选择，Shift 可多选。展开/折叠只影响列表，不占撤销记录。新曲线归入当前图层，新文字自动使用“文字图层”。隐藏或锁定图层不能新增元素。
- 在节点或选取工具中点击画布的曲线、节点、控制柄、图片或文字，自动选中所属图层；点击已经选中的元素也会定位，保留已有多选和节点编辑状态。可见的锁定内容仅定位图层，仍不可编辑；画线、文字创建和提取工具保留当前目标图层。
- **选取**（V）：拖动图片、曲线或选择框内部可整体移动，拖选择框的四角等比缩放。**位置与尺寸** 可精确输入 X、Y、宽和高，单位为画板像素；取消“保持宽高比例”后可分别调整宽高。也可填写“缩放倍数”并点“等比缩放”或按 Enter：2 放大到当前尺寸的两倍，0.5 缩小到一半；始终等比，围绕所选内容共同选框中心缩放，节点与控制柄保持可编辑，支持曲线、图片、文字及多选图层，一步撤销/重做。仅接受大于零的有效倍数；应用后倍数回到 1。标定比例不变，导出实际尺寸随内容缩放。勾选“保留原曲线（生成缩放副本）”后，在各自原图层新增并选中缩放副本，原件不变；混选的图片与文字同样保留原件。缩放后的曲线自动换色，优先使用画布中未占用的颜色，颜色随撤销/重做、保存和刷新恢复。曲线节点和绝对控制柄随元素一起变换，视图缩放不改变作品尺寸。
- **曲线锁定**：展开图层后，点曲线右侧的锁按钮可单独锁定/解锁。锁定后不能选中拖动、修改节点/控制柄、缩放或删除该曲线；锁定开关会结束当前拟合预览，已完成的修改保留。点击所属图层、图层组或多选图层，仍可用圆柄或角度输入一起旋转，包含锁定曲线，曲线锁定状态保持；隐藏内容和锁定图层/祖先组不参与旋转。支持撤销/重做、JSON 和本机自动恢复。
- 图层多选后可“成组”“解组”或“合并”（面板按钮或右键）。Shift 或 Cmd/Ctrl 点击图层名称多选；成组和合并要求同组内相邻图层，以保留与其他图层的叠放关系。组可折叠、嵌套、命名、排序、隐藏、锁定、删除，单选普通层、组或多选任意图层可整体移动、缩放和旋转；选子图层继续编辑。解组保留内容和有效显示/锁定状态。合并归属保留独立曲线、节点、控制柄、图片、文字与混合绘制顺序，不连接曲线或生成位图；显示/锁定状态不一致时提示先统一。操作可一步撤销重做，并随 JSON、操作记录副本和刷新恢复。
- **图层与元素旋转**：从曲线列表选中一条或多条曲线后，直接拖动曲线或选框内部整体移动，方向键移动 1 px、Shift 方向键移动 10 px。选框上方圆柄默认绕所选曲线共同外框的中心旋转，Shift 按 15° 吸附；放大或平移使圆柄超出画布时，圆柄自动移到可视区域内，仍绕当前旋转中心旋转，无需缩小视图；拖动角度显示最多两位小数；也可在“位置与尺寸”填写旋转角度并点“应用旋转”，正数顺时针、负数逆时针，角度为本次相对转动量。节点及控制柄一起变换，操作结束保持原选择，一次操作可一步撤销/重做；节点工具选中节点后仍按原方式编辑节点。图片可使用同一圆柄和角度输入旋转，也可与曲线混选后一起旋转；文字也支持旋转，旋转后仍可修改内容和字号；点击单个普通图层会选中层内可编辑内容，Shift 或 Cmd/Ctrl 可增减任意图层，共同绕当前旋转中心旋转，单独锁定的曲线随图层旋转，隐藏内容和锁定图层不参与。图片原始像素保持不变，角度随作品、操作记录和刷新恢复保存；旋转后仍可移动、等比缩放、提取线条和外轮廓。已旋转图片的宽高输入自动保持比例，位置与尺寸显示旋转后的外接框。
- **自定义旋转中心**：选中整条曲线、图片、文字或多个图层，拖动画布上的橙色十字圆心到任意位置，再拖蓝色旋转圆柄或输入角度，两种方式均绕同一中心旋转。拖动中心时显示可见曲线节点，接近 9 个屏幕像素内自动吸附并变绿；锁定可见曲线也可参考，隐藏曲线不参与。Alt 暂停吸附，Esc 取消本次中心拖动。对象属性 → 位置与尺寸 →“恢复选框中心”恢复默认。自定义中心在同组选区中保持画布坐标，更换元素选区会重置；节点工具中重合处优先编辑曲线节点，按 V 切到选取工具可拖动重合处的中心。中心设置不改变作品、不占撤销步骤，也不清除重做；本机恢复及含操作记录的副本保留中心设置，AI/DXF/SVG 不导出辅助标记。
- 空白处框选，Shift 点击增减选择；全选或 Cmd/Ctrl+A 选择所有可见且未锁定元素。多选图片和曲线后可一起移动、缩放或删除；方向键移动 1 px，Shift 方向键移动 10 px。节点工具的全选只选择节点。
- 图片透明度应用于所选图片。图层设置和变换随 JSON 保存，每次导入、创建文字、删除、排序或拖动可撤销重做。保存配套预览包含可见图片、曲线和文字；“导出…”可按全部可见内容或所选图层导出矢量线稿。

## 镜像与测量

- **镜像**：选择左侧“对称轴”（A），在画板点击两个不同位置定义对称轴，支持任意倾斜方向；第二点接近水平或竖直方向 5° 内会自动吸附，轴旁显示“水平”或“竖直”，移开后恢复自由方向，缩放不改变角度范围。Shift 约束为 45° 倍数，靠近现有节点会吸附；若节点接近水平或竖直，优先矫正为水平或竖直轴。再选择曲线，点击“生成镜像副本”，或右键“按对称轴生成镜像副本”。原曲线保留，副本可独立编辑，节点类型与控制柄一起镜像，操作可撤销。可重新画轴或清除轴；清除轴不会删除已经生成的副本。节点工具（F10）点选两节点之间的线，蓝色高亮后右键“镜像所选片段”，只镜像本段并生成独立开放曲线；镜像面板按钮也跟随选段。保留原曲线、弧度、样式和图层，支持闭合末段、一步撤销/重做及保存恢复；未设置对称轴时禁用并提示先画轴。 轴画好后，节点、选取、对称轴工具均可直接拖动两端点改变位置和角度，普通拖动可自由微调水平、竖直附近的角度，按住 Shift 约束角度；节点、选取或对称轴工具中点选轴线即高亮，可直接拖动整轴平移（延长线也可选）；方向键微调，Shift 方向键移动 10 px，右键“删除对称轴”或 Delete 仅删除轴，保留原曲线和已有镜像副本。选中轴时保留镜像来源选择，移动实时预览；点击曲线或 Esc 退出轴选择。Shift 拖动约束方向，Alt 暂停自动吸附，Esc 取消本次拖动。先选择一条、多条曲线或所选片段，调整轴时绿色虚线实时预览，预览不写入作品或导出；生成的副本独立保留。在对称轴工具中生成副本会保留原对象选择，可继续调整轴、再次生成。每次拖动支持一步撤销/重做，对称轴随 JSON 与本机自动记录恢复。
- 曲线节点吸附对称轴：拖动节点到轴线或其延长线 3 个屏幕像素内，绿色提示并吸附到轴上；移开脱离，Alt 临时取消。多选节点保持相对位置，取最近节点对准；优先连接可连接端点，普通节点和对称轴取较近目标。Shift 保留约束方向；支持一步撤销/重做和保存恢复。
- **节点吸附曲线与线段提示**：拖动节点到其他可见曲线任意位置的 3 个屏幕像素内，自动吸附并显示绿色提示；按实际贝塞尔曲线计算，支持闭合末段。隐藏内容不参与，锁定的可见曲线可作为参考；移动中的曲线不作为自身吸附目标。多节点共用一次平移，控制柄保持相对位置；Shift 保留方向约束，Alt 暂时取消吸附。端点连接优先，其余节点、轴和曲线取最近目标。拖节点或平移整条曲线时，重合线段绿色高亮；邻近直线段只有完全平行或角度差不超过 0.5°、校正位移不超过 6 个屏幕像素时才提示。接近平行显示“松手对齐”，释放鼠标后自动校正为完全平行；只移动一端时微调节点，两端一起移动时对所选曲线节点与控制柄作小角度刚性旋转，保持选区形状。Shift 保留原方向约束，已有节点/曲线吸附和端点连接优先。Alt 暂停吸附和提示，取消手势不自动校正；每次拖动与校正合为一步撤销，提示不写入作品或导出。
- **节点右键菜单**：字号和行距紧凑，仅显示当前选中节点可用的编辑操作；单个开放端点才显示“继续画线”，可断开的单节点才显示“断开连接”，连续多节点才显示圆顺或剪口操作，已有剪口才显示“取消剪口”。导入图片、创建文字、打印及整条曲线操作在画布或曲线菜单使用；已选节点时在空白处右键仍编辑该选区。矮窗口中菜单滚动不会关闭，支持方向键选择。
- **节点颜色**：用节点工具单选、框选或 Shift 多选节点，在“曲线与节点 → 节点颜色”点常用色块即可改色，也可点自定义颜色；右键“设置节点颜色…”能直接打开入口。“清除颜色”恢复普通节点显示。已着色点在取消选择后仍显示，拟合时原位置与随动位置保持同色，剪口节点使用剪口自身的刚性变换；局部拟合只显示选区内的随动点。颜色随 JSON 和本机记录保存，支持撤销/重做，修改颜色不改变几何或曲线线色。节点定位圆点不额外导出为 AI/DXF/SVG 线条。
- **设为剪口**：先用节点工具点选轮廓，再从空白处框住剪口两端和尖点（至少 3 个连续节点），点顶部“设为剪口”，也可右键同名操作。标记变橙色，不改变原坐标；选中剪口任意节点后“取消剪口”只去掉标记。再框选包含剪口的连续缝边，点“局部拟合”、点另一片的边，直接拖橙色剪口，最后“展开并保留修改”。拟合按开口跨过去的临时缝边计算长度，剪口自身完整旋转、平移，宽深和控制柄形状保持。普通范围切入剪口会自动包含整个剪口；直接点选剪口尖点或内部节点作为拟合起终点时，使用它在口部缝边上的投影位置计长，不把凹口绕行长度算入；边界剪口也完整保持宽深和控制柄形状，只作平移、旋转，不拉伸。该边界剪口在拟合视图中仍不可单独改形或加点。连续对合/回撤、拖动取消、撤销/重做和 JSON/本机记录恢复均保留标记。整片模式下，选段外的剪口保持形状随动，但须扩大对合范围后才能拖动。“编辑拟合曲线”中不单独编辑受保护的剪口点；可在原图修改剪口形状，拟合预览随之更新并保持新形状。
- **拟合性能与界面清理**：沿轨道移动复用同一份原曲线映射计算，改变起终点或重建拟合时使用新的映射；缓存有数量上限，不改变几何精度和展开校验。已移除不展示的旧三步提示、旧图示和未实现的立体弯曲占位，保留点选、换侧、剪口、原图/拟合编辑及撤销功能。
- **拟合快捷操作与对比**：每次进入拟合自动展开快捷浮窗，即使上次最小化过；四个起终点按钮立即可用，无需预选整条曲线：点按钮后直接点节点，第一点确定所属曲线，另一端必须在同一条曲线上；原曲线和目标曲线均选好两端后对合，先选目标或先选终点也支持。成功点选后自动按“原曲线起点 → 原曲线终点 → 目标曲线起点 → 目标曲线终点”切换，按钮高亮下一步；无效点选不会推进，仍可手动切换步骤或先选终点。未选齐时标出已选端点，点击起点可重新选其他曲线。画布浮窗提供“原曲线：设起点 / 设终点”和“目标曲线：设起点 / 设终点”，点按钮后再点对应曲线任意节点；当前操作按钮高亮，右侧面板入口同步。原曲线和目标曲线为闭合轮廓时，各自下方单独一行提供“换另一侧绕行”，侧栏同步提供入口，保留已选起终点，切换另一侧路径。目标换侧后固定当前两端，后续调整原曲线范围也保留目标两端。拟合范围高亮跨过已标记剪口的口部直连，与缝边计算一致；剪口原始轮廓仍用细线保留。目标曲线明确设过终点后，修改原曲线范围或原节点仍保留该终点；继续对合到指定目标终点时提示先调整终点。长度不同时显示差值，不拉伸原曲线。浮窗和侧栏的“隐藏拟合曲线 / 显示拟合曲线”控制拟合后的移动副本，包括剪口、节点和定位控件；未拟合原图、固定目标轨道和其他曲线保留。隐藏时退出拟合节点编辑，选择起终点不会自动显示；进入“编辑拟合曲线”时恢复显示。只影响当前预览，不修改图层或保存内容。起点使用小圆点、终点使用小方点，沿线箭头标明方向；节点及金色定位点缩小显示，但保留较大的透明点击区域，分数位置的端点中心也可直接点击换起点。拖动浮窗顶部标题栏（⠿）可移动位置，展开和最小化状态分别记住位置；窗口缩小时保持在画布可见范围内，拖动中按 Esc 取消移动。浮窗只能最小化，不能关闭；点击最小化条或右侧入口可恢复。原曲线和目标曲线旁均可直接打开选色面板，提供常用色块、二维饱和度/亮度色板、色相和十六进制颜色代码；颜色立即同步画布与右侧面板并记住偏好，不改作品颜色或操作历史。
- **局部拟合**：选中一条原曲线后，点左侧“局部拟合”或按 N，再点另一片要贴合的边；想只拟合一部分，先用节点工具框选连续几个点或按 Shift 加选，再按 N。没有预选时仍可依次点两条边。进入拟合后，默认单击原曲线任意节点设为拟合起点；点右侧“点选终点”后，再单击任意节点设终点，修改一端保留另一端。选轨道前后都可调整。开放曲线按起点到终点确定方向；闭合曲线可跨首节点，“换另一侧绕行”切换两端之间的另一段。切换“编辑节点”可恢复普通节点选择和精细拖动。原曲线端点标记周围仍可一键反向，拖中心节点仍修改原图。修改原曲线范围保留轨道起点和对合位置。贴合轨道上的所有节点均可直接单击设为对合起点，首次选轨道时也可直接点节点；重新按原曲线所选长度对合，对合位置归零，原曲线起点不变。中间节点沿当前方向，开放轨道到头时自动向内；闭合轨道可跨原首节点连续对合。原图节点工具下拖动仍修改节点，轻微点击抖动不会移动节点；锁定轨道可选起点但不移动节点。剪口内部节点作为起点时，按口部缝边上的投影位置对合，内部冗余节点不按数量均分位置；所有已标记剪口统一按缝边基线计长，原剪口几何不变。未标记的凹口不会自动猜测为剪口。贴合轨道选定范围的两端也有小标记，点击端点标记周围可设为轨道起点，并把对合位置移回该端（对合位置归零），沿箭头方向重新对合；原曲线起点保持不变。实心小圆点标记轨道起点，另一端标为轨道终点；移动金色点后，轨道端点保持原位，“对合起点”跟随实际位置。实心小圆点与“拟合起点”标记当前起点，另一端标明“拟合终点”；原选段及对合位置沿线显示方向箭头，“对合起点”标出目标边上的对应位置。这些起点与方向提示始终显示，不受“显示画布文字”开关影响；与“反向原曲线 / 反向轨道”按钮同步，切换不改原节点、长度或保存内容。调整范围时端点控件用于拖动范围；拟合视图增删节点后需先展开再重选起点。点选原曲线起终点、切换绕行侧或轨道起点/方向会重新开始连续对合的回退记录，已有曲线修改保留。只把选中的连续段及该范围内的短剪口弯过去，未选轮廓和选区外剪口留在原位，原曲线不拆断；支持闭合轮廓跨起点选择，不连续或跨曲线的选择会提示重选。直接拖橙色剪口可整体移动并保持长度，点“展开并保留修改”带回原形，未修改节点和控制柄保持原坐标。对合完成后默认可直接编辑原图：F10 拖原节点/控制柄、双击加点、Delete 删点，拟合与长度实时重算；B 可画线，也能在其他曲线标记、改形状、使用右键和图层面板。原图修改可撤销/重做且保留拟合；原图增删点会跟踪原选段。若要直接修改弯曲后的预览，点“编辑拟合曲线”，局部两端灰点固定，内部节点、控制柄可编辑，双击加点、Delete 删除内部点；增删后先展开再重选范围。也可直接点一段边开始；“继续对合下一段”或“调整对合范围”用于扩展连续范围。连续对合后可点“退回上一段”逐步回撤范围，保留剪口和曲线修改；左上撤销/重做及 Cmd/Ctrl+Z、Cmd/Ctrl+Shift+Z、Ctrl+Y 支持最近的继续对合操作，新继续会清除已回退的重做分支。若之后实际编辑了剪口或节点，普通撤销仍优先撤销该编辑；只想缩回对合范围时用“退回上一段”。范围记录只在本次拟合中保留，展开后不占作品撤销步骤。画布快捷操作右上角“—”可最小化，保留可点击的恢复入口，不提供关闭按钮；也可在右侧点“显示画布提示”恢复，最小化不退出拟合或修改作品。拟合面板可分别点“原曲线 / 拟合线”和“贴合轨道”的色块即时换色，当前浏览器会记住选择；只改变预览，不修改纸样原有线色。原曲线按所选颜色持续高亮，粗线标出所选范围。画布文字默认隐藏，原曲线和轨道名称显示在右侧，金色定位点保留悬停提示；需要时勾选“显示画布文字”。拖金色对合点时只移动定位点并显示预计落点；松手后曲线和剪口沿固定轨道按弧长滑动，能继续转过后续弯道及闭合起点，不拉长纸样。点击、切换操作或展开会停止移动，取消拖点保持原位置。滑条可直接调整位置，反向按钮切换方向。“更多调整”中的“整片随动”默认关闭，需要时手动开启。缝边按真实弧长映射，不缩放；整片二维随动仅作示意，不可靠的重叠位置拒绝编辑。预览失败保留原线和已有修改。保存、导出与本机记录始终使用展开数据。
- **拟合中修改与展开**：原图编辑默认可用，改原曲线或贴合轨道时实时更新拟合；B 在预览位置画出的新标记按实际画布坐标保留，不自动反算到原曲线。直接编辑弯曲视图时，先点“编辑拟合曲线”；拖动金色对合点或右侧滑条调整对合位置，点击活动曲线后拖节点/控制柄，双击加点，Delete 删除所选点，方向键微调。原形作为底稿，只把实际编辑映射回原坐标；“展开并保留修改”或 Esc 退出，未修改部分原坐标完全保留，主动加长、改短或增删点也保留。修改继续支持自动记录、保存、导出与撤销，保存/导出始终使用展开纸样。Esc 发生在拖动中时仅取消该次手势。弯曲重叠、局部折叠或反向映射不可靠时拒绝修改并提示调整范围。立体弯曲标为“待实现”，当前不提供布料物理模拟。
- **两点或多点距离**：选择“测量”（M）→“点距测量”，连续点击测点。显示各段直线距离和累计值，靠近节点自动吸附。Enter / Esc 或“结束测量”结束，下一次点击开始新的测量；Backspace / Delete 回退一个测点，“清除测量”清空结果。
- **整条曲线**：右键曲线 →“测量整条曲线”，显示沿贝塞尔曲线计算的弧长；闭合曲线包含最后一点回到第一点的线段。
- **连续线段**：选择“测量”→“选段测量”，点首段，再按住 Shift 点末段；按节点顺序选中两段之间的所有线段，包含首尾段。闭合曲线可用“切换闭合曲线另一侧”选择绕过首末节点的范围。也可右键“从这段开始测量”及“测到这一段（连续选段）”。绿色高亮标出所选范围，面板列出每段弧长及总长；单击另一段可重新选择。

**实际长度（mm/cm）**：没有比例的图片，先在“测量”面板点“两点标定”，在图中点两个已知实际距离的位置，填写长度并选择 mm 或 cm，然后点“应用比例”。例如两点的真实距离为 10 cm，就填写 10 并选择 cm。所有点距、累计距离、整条弧长和连续选段会按此比例换算，可通过“测量单位”切换 mm/cm；缩放不影响结果。应用前可取消重新标定并保留原比例，清除比例后恢复 px。标定及单位选择支持撤销重做，随作品 JSON 保存；新建画板会清除比例，需要重新标定；向当前画板导入图片保留现有比例，图片实际比例是否一致需依据已知距离核对。已有标定的 JSON 再次打开时直接复用。

未标定时如实显示原图 **px**，不会猜测毫米长度。标定比例根据两点的直线距离计算，适用于整幅图统一比例；曲线弧长为数值近似，显示到小数点后两位。对称轴和标定信息随 JSON 保存，但参考线不进入导出 SVG；测量点、结果和高亮仅在当前画布临时显示，不保存、不导出。

## 保存与后续沟通

点击 **保存给 AI** 或 Cmd/Ctrl+S，会在当前项目工作区的保存目录中新增一份 JSON 和配套叠图 SVG。实际目录见启动输出或 `/api/health.saves`，每个工作区有独立的 `latest.txt`。JSON 包含图层、图片位置与尺寸、文字内容与字号、画板像素尺寸、贝塞尔节点及手柄、线条用途和备注；每次保存保留旧版本。此入口仅保存当前作品，不包含操作记录或历史图片，减少 AI 读取量。

保存后，在聊天中说“按通用矢量图编辑器最新保存的曲线改”，助手即可读取项目内的实际坐标。保存本身不会自动发送聊天或修改纸版。

**另存为…** 或 Cmd/Ctrl+Shift+S：保存含最近 100 步操作记录的独立 JSON 副本，包括当前撤销/重做位置、选中状态和历史中使用过的图片。点击后在编辑器内输入文件名，确认“保存副本”后下载到浏览器的下载位置；底部提示可在浏览器下载列表查看。取消或写入失败不改变作品，记录中的图片内容去重。另存为不更新项目的 `latest.txt`；给 AI 读取仍使用“保存给 AI”。副本使用紧凑 JSON 减少体积，作品与记录合计最多 256MB；“打开修改”支持相同上限，不会悄悄丢弃记录。

**打开修改**可重开本工具保存的 JSON；含记录的副本会恢复其操作记录、当前位置和选择，可以继续撤销、重做或重放，不混入打开前作品的记录。旧文件与“保存给 AI”的文件仍可打开，但没有携带历史，无法凭空补回旧操作；启动时优先恢复本机浏览器中的当前作品与操作记录，没有可用记录时恢复最新保存。本机浏览器草稿用于刷新恢复，“保存给 AI”仍是生成项目内可读取、可备份的版本文件。

## AI / DXF 与带尺寸的图层导出

**打开修改**选择 `.ai` 或 `.dxf`，也可直接拖入画布。支持的线稿会成为可拖动节点和控制柄的曲线，保留图层、闭合状态及实际尺寸。文件最多 16MB；解析失败或取消时保留当前作品，替换未保存作品前会提示确认。这里的 AI 文件格式与“保存给 AI”按钮不同，后者仍是保存给助手读取的 JSON。

- **尺寸**：AI 按 1 点 = 25.4/72 mm 换算；DXF 使用文件的单位。DXF 没有单位时会要求选择 mm、cm、m、英寸或英尺，不自动猜测。导入后对象属性显示实际毫米宽高，导出窗口显示所选内容的毫米范围。旧 JSON、照片描线仍需“两点标定”；缩放图形会同步改变实际尺寸。
- **导出范围**：顶部“导出…”默认选择 AI、导出全部可见内容；文件名默认使用当前图名加当天日期（如“1号大师版10.18.ai”），导出所选图层也使用图名，可手动修改；图层面板或右键的“导出所选图层…”导出当前选中的图层及组内可见子层。隐藏图层/曲线不导出，锁定但可见的曲线会导出。嵌套组展开为带父级名称的普通图层；DXF 同名层自动加后缀以保持独立。窗口显示当前范围的曲线总数、原曲线节点数 → 实际导出曲线节点数，以及毫米宽高；控制柄不计入曲线节点。各格式预览来自真实生成的文件：AI 读回核对节点，DXF 数折线顶点/样条曲线端点，SVG 数路径节点。文件坐标点另列：DXF 为样条控制点与折线顶点；AI/SVG 为坐标点总数及其中的控制柄点，包含文件闭合重复点。切换格式、方式、范围同步更新；此统计不代表外部软件再次转换后的节点数。
- **DXF**：导出带毫米单位的 R2000 二维 DXF，打开窗口或切换范围时比较“保留曲线”和“折线兼容”的实际导出曲线节点数（不含控制柄），默认选更少的方式；数量相同则选保留曲线。手动切换仍可选另一种。计算期间暂停导出，失败明确提示；只有一种可用时选择可用方式。折线兼容将贝塞尔转换成连续折线，最大近似偏差 0.01 mm；保留曲线以三次 SPLINE 保存贝塞尔几何、控制柄、尖角和闭合段，不采样成密集折线，纯直线路径仍输出 LWPOLYLINE。两种方式均保留图层、闭合状态和真实尺寸；样条可重新导入本编辑器继续编辑。外部软件须支持 SPLINE，可能显示不同数量的控制点，不保证与编辑器的节点数相同；不支持时用折线兼容。已有密集折线不会自动恢复成少节点曲线，导出不修改原作品或操作记录。
- **AI（默认）**：导出兼容型 Illustrator 矢量线稿，使用标准点单位，保留贝塞尔曲线、闭合状态和图层。它不是包含全部 Illustrator 特效与编辑信息的现代原生文档。
- **文字随 AI / DXF 导出**：在图层列表按 Shift 多选曲线层及文字层，再选“导出所选图层…”。macOS 使用本机系统字体轮廓导出中文、英文、数字、多行及旋转文字，保留字号、颜色、位置、图层与实际比例；点位标注的圆点与引线也包含。文件中的文字是轮廓线，不依赖接收方字体，不再作为文字输入编辑；画布中的原文字和操作记录不变。预览显示转曲轮廓数，导出曲线及节点总数包含文字轮廓，尺寸按真实轮廓计算。缺字、无可用轮廓或平台不支持时明确报错，不静默省略。
- **SVG**：导出可见曲线和文字，文件宽高显式写入毫米，内部坐标保持比例。画板外曲线包含在导出范围内，参考线/手柄不导出。

目前支持 AI 的传统线稿、部分 PDF 容器线稿及本项目 CorelDRAW 样稿的 Illustrator 私有线稿；DXF 支持直线、多段线、圆/圆弧、椭圆、部分线性/三次样条和二维块变换。复杂填充、剪切、透明特效、文字、位图、三维 DXF 及不支持的样条会明确提示，不能当作完整 Illustrator/CAD 文档编辑器。AI/DXF 导出可含文字，文字在导出副本中转为轮廓线；SVG 保留文字；图片层需隐藏或排除。导出保留当前比例和曲线间相对位置（AI 按整体内容移至原点），不自动添加尺寸标注线、缝份、割缝补偿或机器加工参数。

## 复用到其他项目

已安装为个人 Skill：`~/.codex/skills/vector-editor/`（若设置了 `CODEX_HOME`，则在该目录下的 `skills/vector-editor/`）。完整编辑器和心形示例都在 Skill 内，独立于本项目。

在其他项目的新对话中说“使用 $vector-editor 打开通用矢量图编辑器”，即可调用共用工具，文件保存在那个项目自己的 `work/curve_editor/sessions/` 下，不用复制本项目。默认按 Codex 会话隔离；同一会话重开恢复，不同会话各自保存画布、记录和作品。

也可以直接启动：

```sh
python3 "${CODEX_HOME:-$HOME/.codex}/skills/vector-editor/scripts/launch.py" --project "/实际的项目目录" --open
```

默认会话 ID 依次取 `CODEX_THREAD_ID`、`CODEX_SESSION_ID`，可用 `--session ID` 显式指定。没有环境身份时每次启动新建独立 ID；页面顶部悬停“独立会话”或读取 `/api/health.workspace.id` 可查看，再用 `--session` 重开。独立保存目录为 `sessions/isolated/<会话ID的SHA-256>/`。

需要共享时，在同一项目的不同聊天说“使用共享工作区「协作稿」打开编辑器”，或在启动命令中加入 `--shared "协作稿"`。同名工作区共用 `sessions/shared/<名称的SHA-256>/` 的作品版本，保存后其他会话重新打开即可接续。保留启动输出的完整 URL，包括 `?client=...`；各成员的浏览器草稿和历史分别保存，未保存草稿、本地导入或仅另存为的作品优先保留；当前画布已保存到共享工作区且没有后续修改时，重开会接续其他成员的最新保存，未修改的初始练习画布也会接续首个共享保存。共享不是实时同步，每次保存均新增版本；同一成员不要同时编辑相同地址的多个标签页。

将原有作品转入共享时，先保存原页面，在共享页面用“打开修改”导入实际保存的 JSON，再“保存给 AI”。旧版项目存档通过 `--shared default` 打开，仍保留原 `sessions/` 根目录及全部版本，新会话不自动读入旧存档。服务只复用身份、保存目录和版本一致的工作区，旧页面不会被自动关闭或刷新。

项目目录必须存在。不同项目自动选择不同端口；只复用保存目录与项目身份都匹配的服务。连接信息记在项目的 `work/curve_editor/server.json`，启动时会验证服务身份，不盲信过期记录。原有旧版服务没有项目身份，不会误复用。

本项目的双击入口优先使用已安装 Skill；未安装时回退到项目源码。若要在没有 Skill 的电脑使用，可复制 `tools/curve-editor/` 和根目录启动入口，仍能独立运行。

需要继续编辑已有作品时，另行复制相应保存 JSON，再用“打开修改”读取。保存文件格式标识 `daban-curve-editor` 为兼容旧文件保留，无须手动更改。

## 当前边界

节点与控制柄仍以原始图像像素为坐标；设置两点标定后，测量可换算为 mm/cm。SVG 尺寸和坐标仍保持像素单位，说明中记录标定比例。当前不直接解析 AI / CDR，不应把输出直接当作生产切割稿。名称“通用矢量图编辑器”不代表已具备完整 CorelDRAW 的全部功能。

## 维护位置

- `index.html` / `style.css`：界面。
- `app.js`：编辑、导入、保存和右键操作。
- `geometry.js`：贝塞尔曲线与保形分割。
- `offset.js`：多段轮廓拼合、实际距离换算、开放/闭合等距偏移与贝塞尔拟合；`offset-fit.js` 优先以原节点拟合闭合轮廓，并以双向距离上界核验候选结果；`vendor/clipper.js` 为随工具附带的本机闭合轮廓算法，许可见同目录，不需要另行安装或联网。
- `interactions.js`：双击识别、多步撤销重做与连续操作合并、重放时间线和去重的本机记录格式。
- `layers.js`：图层归属、旧文件转换、图片校验与元素变换。
- `tracing.js`：本机图片线条跟踪、断口连接、物体外轮廓提取和曲线拟合。
- `server.py`：仅本机可访问的服务及版本化保存。
- `skill/`：Skill 使用说明、启动脚本、格式参考和界面元数据。
- `install_skill.py`：将当前源码与 Skill 模板安装/更新到个人 Skill 目录；只复制工具与示例，不复制用户作品。修改后运行 `python3 tools/curve-editor/install_skill.py` 同步共用版。
- 项目中的 `tests/curve-editor/`：几何、交互及跨项目保存隔离测试。
- `node --test tests/curve-editor/*.test.cjs` 与 `python3 tests/curve-editor/server_test.py`：无额外依赖的必跑验证。`node --test tests/curve-editor/*browser_test.cjs` 为浏览器集成测试，覆盖镜像测量、历史、图层及列表交互、多选、侧栏分组及真实剪贴板粘贴，需要 Playwright 及 Chromium；可设置 `NODE_PATH` 指向运行环境的依赖目录，或设置 `CURVE_EDITOR_BROWSER_CHANNEL=chrome` 使用已安装的 Chrome。测试均使用独立临时项目。
- 项目根目录 `HANDOFF.md`：迁移交接与当前状态。

状态栏按最近实际编辑时间倒序排列。名称与信息统一左对齐，条目交替底色；名称使用深色文字和悬停高亮，右侧提供打开图标，后接 `[正式]` / `[测试]` 标签；固定作品 ID 可直接复制，改名和换端口后仍不变。页面顶部与保存的 JSON 同时提供 `drawingId`。AI 可用 `python3 tools/curve-editor/manager.py lookup --query "作品名称或图-ID"` 查找名称、ID、完整地址和对应保存目录；不同作品重名时返回歧义标记，须按 ID 确认。测试使用 `CURVE_EDITOR_EDITION=test`、临时项目和 `--port 0`。

维护发布后，由 Codex 先只读确认页面显示“已保存在本机 · 刷新可恢复”，然后按原项目、工作区、保存目录和端口重启需要更新的服务。不要额外点击保存或擅自刷新用户画布；核对原地址已提供新版后，用户刷新即可使用。

### 关联对称

镜像默认勾选“生成镜像时记住对称关系”。右键改好的一侧 → “以这一侧同步另一侧…” → 预览后应用。两半连接成闭合轮廓后也支持；整体移动/旋转前选中对称两侧，轴自动跟随。“显示对称轴”只隐藏辅助线，解除关联另有按钮。普通复制及取消关联选项的镜像仍独立，所有修改可撤销并随本机记录恢复。删除关联的另一侧后，可右键“以这一侧重新生成另一侧…”按记住的关联轴预览并生成新镜像，保留当前一侧及图层，支持一步撤销；“生成镜像副本”也可直接按当前绘制轴建立新的关联，无需先手动解除失效关联。旧版作品没有关联元数据，不自动猜测。

- 刷新与关闭页面：本机自动记录已完成时不再弹出浏览器的“可能不会保存更改”确认框，刷新后恢复画布与撤销/重做记录；尚未完成记录或本机记录不可用且有未保存修改时仍保留提醒。新建或打开其他作品前的覆盖确认保持不变。

- **简化曲线点**：选中一条或多条曲线，在画布或曲线列表右键“简化曲线点…”，也可用“曲线与节点”面板同名按钮。默认允许偏差 0.01 mm，未标定默认 0.1 px；支持 mm/cm/px，未标定只提供 px。绿色叠加显示简化轮廓与新节点，显示各条及合计节点数；滚轮缩放、拖动画布平移，取消/Esc/预览中刷新不改作品。仅在减少节点且整条轮廓双向偏差核验通过时应用，保留端点、尖角、剪口、彩色节点、点位标注锚点、图层与样式；一步撤销/重做并自动记录。简化是显式容差内的近似，不保证零误差或数学全局最少；当前容差无法安全减少时保持原样。关联对称曲线需先解除关联，避免破坏两侧节点关系；隐藏/锁定曲线不可简化。

- **两点尺寸标注**：先用两点标定设置实际比例，再点击左侧“尺寸标注”并点击两个位置，显示两点直线距离（mm/cm，保留两位小数）。默认放入“尺寸标注”图层；选中后拖两端圆点调整位置，拖方块调整尺寸线间距，属性区可改字号和单位。端点在创建或拖动时吸附可见节点并建立关联，原节点移动时尺寸线与数字实时更新；旧标注端点与某节点唯一重合时会在几何编辑中接续关联。插入节点保留原关联，删除关联节点或曲线后保留最后位置并解除该端关联。按 Alt 拖端点可解除关联；单独移动或变换整个标注会解除不在同一变换中的曲线关联，拖方块只调整间距。标注支持移动、等比缩放、旋转、撤销、保存及自动恢复；标定改变时重新计算。清除比例后显示“未标定”，恢复有效比例才能导出。AI/DXF/SVG 均带尺寸线、箭头与数字；AI/DXF 数字转轮廓，尺寸线为普通矢量线，不是 CAD 关联式 DIMENSION 实体。按所选图层导出时请一起选中标注所在图层。

DXF 样条导入兼容：支持夹持的非有理三次贝塞尔分段，内部结点可重复三次（共享端点）或四次（重复保存同一端点），也可混合；保留原控制柄和形状，不采样成折线。四重结点处端点不重合时明确报错，不自动补线；其他一般 B 样条、周期样条及有理权重仍不支持。无单位文件仍须手动选择单位。

### 右键增加剪口

在曲线上所需位置右键选择“增加剪口”，生成口宽与深度 1:1 的 V 形剪口，并自动标记为保持形状的剪口。口宽默认取曲线包围盒长边的 1.5%；已标定时常规尺寸限制为 0.8–3 mm。短曲线、开放端点附近、已有剪口附近和狭窄闭合轮廓会继续缩小，避免越界。闭合轮廓朝内，开放曲线朝节点前进方向的左侧。精确开放端点、已有剪口内部、对称关联未解除或空间不足时提示原因且不修改。拟合预览中先展开再添加。

剪口直接写入原曲线的可编辑节点，保留外侧贝塞尔弧线，支持一次撤销、重做、本机自动恢复和 AI / DXF / SVG 实际线稿导出。尺寸由作品坐标及标定决定，与屏幕缩放无关。

### PLT 线稿导入

“打开修改”或拖入画布支持 `.plt`（HP-GL 折线），按 40 单位/mm 转为可编辑节点，保留抬笔分段、闭合轮廓及笔号图层，并自动标定实际尺寸。支持 IN、SP、PU/PD、PA/PR，接受 VS/PW/WU 机器参数；笔宽按编辑器默认线宽显示。当前不支持圆弧、文字、自定义缩放、旋转及虚线指令，遇到这些内容会明确拒绝，保留当前作品。PLT 仅导入，导出仍为 AI/DXF/SVG。

### 按实际尺寸追加线稿

顶部“导入线稿”或直接拖入 AI / DXF / PLT，会追加到当前画布的新图层；原作品名称、图片、文字、曲线和操作记录保留。导入内容放在当前视野中心，拖入时放在落点，并选中新曲线。已有标定时按文件与画布的实际比例换算节点和控制柄，不改原画布比例；提示导入件的毫米宽高。空白画布自动采用文件比例；有内容但未标定时先暂存文件，进入两点标定，填写原图中两点已知的实际长度并“应用比例”后自动继续导入。取消标定、切换作品或撤销会取消待导入内容。追加支持一步撤销/重做和本机恢复；“打开修改”仍是打开另一份作品。

### 扫描图片区域清理

推荐快捷流程：选中闭合曲线 → 右键“反选图片外区域” → 画布上红色高亮圈外 → 再次右键“删除所选图片区域”（或 Delete / Backspace）。第二次右键也可“反选图片区域”切换圈内/圈外；Esc、“取消图片区域选择”、普通点击或切换工具取消选区。反选只是临时预览，尚未删除；刷新不保留这个临时选区。

新提取的轮廓记住来源图片，曲线和图片无需同层；旧轮廓优先处理同层图片，没有同层图片时自动找范围内唯一的可编辑图片。存在多张重叠候选时，按 Shift 加选目标图片后使用；记住的来源图被删除、隐藏或锁定时明确提示，不误用其他图。圈外以目标图片边缘为界，适用于无限画布，无需毫米标定；不会删除图片之外的空白画布。顶部及右键“图片区域清理…”仍可打开详细预览。

删除处变透明；曲线、非目标图片、图片位置、旋转、实际尺寸及原始像素分辨率保留。多张目标图片暂存成功后一步提交，可撤销/重做，本机恢复与 JSON 保留结果；原扫描文件不覆盖。处理失败或中途取消不提交部分结果；超过 6400 万像素或单边 32767 像素的图片明确提示先分割，不降低分辨率。来源关联随保存恢复保留，复制时随同复制的图片重新关联；只复制曲线时不继承旧图关联。
